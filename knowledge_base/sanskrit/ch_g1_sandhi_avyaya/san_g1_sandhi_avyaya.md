## पाठ्यविषयः एवं व्याकरण-नियमाः (Theory & Grammar Summary)

### १. स्वरसन्धि-नियमाः (The 7 Rules of Swara Sandhi)
1. सवर्णदीर्घः: अक् + सवर्ण अक् = दीर्घः (अ+अ=आ, इ+इ=ई, उ+उ=ऊ, ऋ+ऋ=ॠ)। सूत्रम्: 'अकः सवर्णे दीर्घः'।
2. गुणः: अ/आ + इ/ई = ए, अ/आ + उ/ऊ = ओ, अ/आ + ऋ = अर्। सूत्रम्: 'आद्गुणः'।
3. वृद्धिः: अ/आ + ए/ऐ = ऐ, अ/आ + ओ/औ = औ। सूत्रम्: 'वृद्धिरेचि'।
4. यण्: इ->य्, उ->व्, ऋ->र्, ऌ->ल् (असमानस्वरे परे)। सूत्रम्: 'इको यणचि'।
5. अयादिः: ए->अय, ओ->अव, ऐ->आय, औ->आव (स्वरे परे)। सूत्रम्: 'एचोऽयवायावः'।
6. पूर्वरूपम्: ए/ओ + ह्रस्व अ -> एऽ / ओऽ। सूत्रम्: 'एङः पदान्तादति'।
7. प्रकृतिभावः: ईदूदेद् द्विवचनं प्रगृह्यम् (हरी एतौ, लते एते - अत्र सन्धिः न भवति)।

### २. अव्यय-परिचयः (Concept of Indeclinables)
'सदृशं त्रिषु लिङ्गेषु सर्वासु च विभक्तिषु। वचनेषु च सर्वेषु यन्न व्येति तदव्ययम्॥' (That which remains invariant across all 3 genders, all 7 cases, and all 3 numbers is an Avyaya). Avyayas never decline or conjugate.
