1. Place Value & Representation

The Need for Smaller Units, Tenths, Hundredths, Thousandths, and Place-Value Chart.

NCERT pp. 49–53

The Need for Smaller Units

In daily life, measurements cannot always be expressed as whole numbers. A pencil might be longer than $7\text{ cm}$ but shorter than $8\text{ cm}$; the petrol filled in a car is rarely an exact whole number of litres. To measure and compare these tiny differences accurately, we divide whole units into smaller equal parts called decimals.

Key Concept: The dot '$.$' separating the whole number part from the fractional part is called the decimal point. Digits to the left represent whole units ($1, 10, 100, \dots$), while digits to the right represent fractional parts ($\frac{1}{10}, \frac{1}{100}, \frac{1}{1000}, \dots$).

1. A Tenth Part ($\frac{1}{10} = 0.1$)

When $1\text{ whole unit}$ is divided into $10$ equal parts, each part is called one-tenth: $$1\text{ tenth} = \frac{1}{10} = 0.1$$ Since $1\text{ cm} = 10\text{ mm}$, $1\text{ mm} = \frac{1}{10}\text{ cm} = 0.1\text{ cm}$. A length of $4\text{ cm and } 6\text{ mm}$ is written as $4.6\text{ cm}$ and read as "four point six centimetres" or "four and six-tenths centimetres".

2. A Hundredth Part ($\frac{1}{100} = 0.01$)

When each tenth is further divided into $10$ equal parts, the whole unit is divided into $100$ equal parts: $$1\text{ hundredth} = \frac{1}{100} = 0.01$$ Since $\text{₹}1 = 100\text{ paise}$, $1\text{ paisa} = \frac{1}{100}\text{ rupee} = \text{₹}0.01$. Similarly, $1\text{ m} = 100\text{ cm}$, so $1\text{ cm} = 0.01\text{ m}$.

3. A Thousandth Part ($\frac{1}{1000} = 0.001$)

Dividing a hundredth into $10$ equal parts divides the whole unit into $1000$ equal parts: $$1\text{ thousandth} = \frac{1}{1000} = 0.001$$ Since $1\text{ kg} = 1000\text{ g}$, $1\text{ g} = 0.001\text{ kg}$. Since $1\text{ km} = 1000\text{ m}$, $1\text{ m} = 0.001\text{ km}$.

Decimals on the Number Line

Every decimal corresponds to a unique point on the number line. To locate tenths, divide the segment between whole numbers into $10$ equal parts. To locate hundredths, divide each tenth into $10$ equal sub-parts.

Example: $1.3$ lies between $1$ and $2$, exactly $3$ tenths to the right of $1$. Point $2.75$ lies midway between $2.7$ and $2.8$.

2. Comparing, Ordering & Conversions

Like and Unlike Decimals, The Zero Dilemma, Ascending/Descending Order, and Conversions.

NCERT pp. 54–57

The "Zero Dilemma" in Decimals

A fundamental property of decimal notation: Are $1.3$, $1.30$, and $1.300$ equal or different?

Golden Rule of Trailing Zeros: Annexing (adding) zeros to the extreme right of the decimal part does not change its value.
$$1.3 = 1 + \frac{3}{10} = 1 + \frac{30}{100} = 1.30 = 1 + \frac{300}{1000} = 1.300$$
Critical Distinction: Adding zeros between the decimal point and a non-zero digit completely changes the value!
$$0.5 \neq 0.05 \neq 0.005$$ ($5\text{ tenths} = 500\text{ thousandths}$, whereas $5\text{ hundredths} = 50\text{ thousandths}$, and $5\text{ thousandths} = 5\text{ thousandths}$).

Like and Unlike Decimals

  • Like Decimals: Decimals having the same number of decimal places (e.g., $4.25, 18.70, 0.35$ all have 2 decimal places).
  • Unlike Decimals: Decimals having different numbers of decimal places (e.g., $3.2, 4.15, 0.789$).

Conversion Rule: Annex trailing zeros to the number with fewer decimal digits to make all numbers like decimals.

Example: Convert $2.5$ and $3.125$ to like decimals $\implies 2.500$ and $3.125$.

Rules for Comparing Decimals

  1. Compare Whole Number Parts: The decimal with the greater whole number part is greater (e.g., $\mathbf{45.2 > 9.999}$ because $45 > 9$).
  2. If Whole Parts are Equal: Compare the tenths digits. The one with the greater tenths digit is greater (e.g., $\mathbf{3.71 > 3.49}$ because $7 > 4$).
  3. If Tenths are Equal: Compare the hundredths digits (e.g., $\mathbf{0.854 > 0.829}$ because $5 > 2$).
  4. If Hundredths are Equal: Compare the thousandths digits (e.g., $\mathbf{12.438 > 12.434}$ because $8 > 4$).

Conversions: Fractions & Decimals

1. Fractions to Decimals:

  • If denominator is $10, 100, 1000$: Place the decimal point as many places from the right as there are zeros in the denominator (e.g., $\frac{254}{1000} = 0.254$, $\frac{16}{100} = 0.16$).
  • If denominator is not a power of 10: Multiply numerator and denominator by a factor to make denominator $10, 100,$ or $1000$: $$\frac{3}{4} = \frac{3 \times 25}{4 \times 25} = \frac{75}{100} = 0.75,\quad \frac{4}{5} = \frac{8}{10} = 0.8,\quad \frac{1}{8} = \frac{125}{1000} = 0.125$$

2. Decimals to Fractions:

Write the decimal without point in the numerator, and $1$ followed by as many zeros as decimal places in the denominator. Simplify to lowest terms:

$$0.06 = \frac{6}{100} = \frac{3}{50},\quad 0.375 = \frac{375}{1000} = \frac{3}{8}$$

3. Addition & Subtraction of Decimals

Columnar alignment, borrowing across the point, decimal sequences, and word problems.

NCERT pp. 58–62

Fundamental Columnar Alignment Rule

Rule: Always align numbers vertically so that the decimal points are strictly in the same vertical column. Annex trailing zeros to equalize decimal places before adding or subtracting.

Carry over or borrow across the decimal point just like with whole numbers!

Estimating Sums and Differences

Estimation provides an instant check against errors:

  • Sum Estimation: For $4.7 + 3.9$, lower bound is $4 + 3 = 7$; upper bound is $(4+1) + (3+1) = 9$. Actual sum ($8.6$) lies between $7$ and $9$.
  • Difference Estimation: For $92.6 - 47.8$, whole part difference is $92 - 47 = 45$. Actual result ($44.8$) is very close to $45$.

4. Multiplication of Decimals

Multiplication by powers of 10, decimal by whole number, and decimal by decimal.

NCERT Decimals Core

1. Multiplying by Powers of $10$ ($10, 100, 1000$)

Rule: Shift the decimal point to the RIGHT by as many places as there are zeros in the multiplier.
  • $1.25 \times 10 = \mathbf{12.5}$ (shift right 1 place)
  • $1.25 \times 100 = \mathbf{125}$ (shift right 2 places)
  • $1.25 \times 1000 = \mathbf{1250}$ (shift right 3 places; annex 0)

2. Multiplying Decimal by Decimal

Product Rule: Multiply as whole numbers. The number of decimal places in the product is the SUM of decimal places of the two factors.

Example: $0.15 \times 0.4$: $15 \times 4 = 60$. Total decimal places $= 2 + 1 = 3 \implies \mathbf{0.060} = \mathbf{0.06}$.

5. Division of Decimals

Dividing by powers of 10, whole numbers, and decimal by decimal division.

NCERT Decimals Core

1. Dividing by Powers of $10$ ($10, 100, 1000$)

Rule: Shift the decimal point to the LEFT by as many places as there are zeros in the divisor.
  • $31.5 \div 10 = \mathbf{3.15}$ (shift left 1 place)
  • $31.5 \div 100 = \mathbf{0.315}$ (shift left 2 places)
  • $31.5 \div 1000 = \mathbf{0.0315}$ (shift left 3 places; prefix 0)

2. Dividing a Decimal by another Decimal

Golden Rule: Multiply both dividend and divisor by $10, 100,$ or $1000$ to turn the divisor into a WHOLE NUMBER, then divide normally.

$$\frac{7.65}{0.15} = \frac{7.65 \times 100}{0.15 \times 100} = \frac{765}{15} = \mathbf{51}$$

Decimals as Fractions with Powers of 10

Decimals are fractions whose denominators are powers of $10$ ($10, 100, 1000, \dots$). The number of digits after the decimal point indicates the power of ten in the denominator:

$$\frac{2}{10} = 0.2, \quad \frac{6}{100} = 0.06, \quad \frac{7}{1000} = 0.007$$

The number of digits in the decimal part is called the number of decimal places. For example, $3.456$ has $3$ decimal places.

Like Decimals

Decimal numbers having the same number of decimal places are called like decimals.

Examples: $5.17$, $19.25$, and $216.42$ all have exactly $2$ decimal places.

Golden Rule: Appending trailing zeros after the last decimal digit does NOT alter the value: $$0.4 = 0.40 = 0.400 = 0.4000$$
Unlike Decimals

Decimal fractions having different numbers of decimal places are called unlike decimals.

Examples: $12.5$ (1 place), $13.72$ (2 places), and $18.564$ (3 places).

To Convert Unlike to Like Decimals: Identify the maximum decimal places and append requisite zeros to the others:

$$12.5 \rightarrow 12.500, \quad 13.72 \rightarrow 13.720, \quad 18.564 \rightarrow 18.564$$

Two-Way Conversion Protocol

Type I: Decimal to Fraction in Lowest Form
  1. Remove the decimal point to form the numerator.
  2. In the denominator, write $1$ followed by as many zeros as decimal places.
  3. Divide numerator and denominator by their HCF to reduce to lowest terms.
$$\text{Example: } 2.064 = \frac{2064}{1000} = \frac{2064 \div 8}{1000 \div 8} = \mathbf{\frac{258}{125}}$$
Type II: Fraction to Decimal (Denominator Scaling)
  1. Find a scaling factor to make the denominator $10, 100, 1000$ (factors: $2 \times 5 = 10$, $4 \times 25 = 100$, $8 \times 125 = 1000$).
  2. Multiply numerator and denominator by the factor.
  3. Insert the decimal point as many places from the right as zeros in denominator.
$$\text{Example: } 12\frac{1}{8} = 12 + \frac{1 \times 125}{8 \times 125} = 12 + \frac{125}{1000} = \mathbf{12.125}$$

Standard Operating Procedure: 4-Step Decimal Comparison

Step 1: Convert to Like
Pad with trailing zeros to match decimal places.
Step 2: Compare Whole Parts
Greater whole number is greater (e.g. $16.1 > 15.9$).
Step 3: Compare Tenths
If whole parts match, higher tenths digit wins ($15.40 > 15.36$).
Step 4: Compare Hundredths
Proceed rightwards digit-by-digit until a difference appears.

Rule 1: Powers of 10 Right-Shift

When multiplying a decimal by $10^n$, the decimal point moves $n$ places to the RIGHT:

  • $\times 10$ ($1$ zero) $\rightarrow$ shift $1$ place right: $7.24 \times 10 = \mathbf{72.4}$
  • $\times 100$ ($2$ zeros) $\rightarrow$ shift $2$ places right: $7.24 \times 100 = \mathbf{724}$
  • $\times 1000$ ($3$ zeros) $\rightarrow$ shift $3$ places right: $7.240 \times 1000 = \mathbf{7240}$
Rule 2: Decimal $\times$ Whole Number
  1. Multiply the numbers as whole integers (ignoring the point).
  2. Mark the decimal point in the product to have the same number of decimal places as the original decimal.
$$\text{Example: } 0.0361 \times 18$$ $$361 \times 18 = 6498 \quad (4\text{ decimal places})$$ $$0.0361 \times 18 = \mathbf{0.6498}$$

Rule 3: Decimal $\times$ Decimal (The Additive Places Law)

When multiplying two decimals, the total decimal places in the product is the sum of decimal places in the factors:

$$\text{Decimal places in product} = \text{Places in Multiplicand} + \text{Places in Multiplier}$$
$$\begin{array}{r@{\quad}l} 0.032 & (3\text{ decimal places}) \\ \times 0.416 & (3\text{ decimal places}) \\ \hline 32 \times 416 = 13312 & \\ \text{Total places needed} = 3 + 3 = 6 & \rightarrow \mathbf{0.013312} \quad \text{(Prepend zero to get 6 digits)} \end{array}$$

Multi-Factor Products: $a \times b \times c$

For chain products like $0.457 \times 26.8 \times 23$:

  1. Multiply entire integer values: $457 \times (268 \times 23) = 457 \times 6164 = 2816948$.
  2. Sum total decimal places: $3 \text{ (from 0.457)} + 1 \text{ (from 26.8)} + 0 \text{ (from 23)} = 4\text{ decimal places}$.
  3. Insert point $4$ places from right: $\mathbf{281.6948}$.

Rule 1: Powers of 10 Left-Shift

When dividing a decimal by $10^n$, the decimal point moves $n$ places to the LEFT:

$$\frac{23.5}{10} = \mathbf{2.35}, \quad \frac{23.5}{100} = \mathbf{0.235}, \quad \frac{23.5}{1000} = \mathbf{0.0235}$$

Mental check: Division makes the quantity smaller, so the point must march leftward!

Rule 2: Decimal by Whole Number
  1. Divide the whole number part first.
  2. Place the decimal point in the quotient immediately before taking down the tenths digit.
  3. If the remainder is non-zero, annex zeros to the dividend and continue until remainder is $0$.
$$62.64 \div 12 = \mathbf{5.22}, \quad 0.672 \div 14 = \mathbf{0.048}$$

Rule 3: Decimal $\div$ Decimal (The Divisor Integralization Law)

Universal Golden Rule: Never divide by a decimal divisor! Always transform the divisor into an integer by multiplying both dividend and divisor by $10^k$ (where $k$ is the number of decimal places in the divisor):

$$\frac{26.313}{1.75} = \frac{26.313 \times 100}{1.75 \times 100} = \frac{2631.3}{175} = \mathbf{15.036}$$ $$\frac{3.411}{37.5} = \frac{3.411 \times 10}{37.5 \times 10} = \frac{34.11}{375} = \mathbf{0.09096}$$

Olympiad / HOTS
Trap 1: The Invisible Zero in Division

Trap: Dividing $1.001$ by $14$. Many students compute $1001 \div 14 = 71.5$ and write $0.715$.

Correct Analysis: In $1.001 \div 14$:

  • $1 < 14 \rightarrow 0.$
  • Tenths digit is $0$: $10 < 14 \rightarrow$ must place $0$ in hundredths quotient place!
  • Take hundredths: $100 \div 14 = 7$ with remainder $2$.
  • Take thousandths: $21 \div 14 = 1$ with remainder $7$. Annex zero: $70 \div 14 = 5$.
  • ✅ Correct quotient: $\mathbf{0.0715}$.

Misconception Analysis: Digits vs Value
Will a decimal number with more digits always be greater than a decimal number with fewer digits? Explain with examples.
Show Step-by-Step Solution

No, definitely not! This is a common misconception carried over from whole numbers.

Reason: The value of a decimal number is determined by the place value of its highest non-zero digit, not the total count of digits.

Counter-examples:

  • $0.12345$ has 5 decimal digits, while $0.9$ has only 1 decimal digit. Yet, $\mathbf{0.9 > 0.12345}$ because $9\text{ tenths} > 1\text{ tenth}$.
  • $5.2$ (2 digits) is much greater than $4.9999$ (5 digits) because the whole part $5 > 4$.
  • $0.0008$ (4 decimal digits) is far smaller than $0.8$ (1 decimal digit).

Rule: To compare decimals, always compare place by place from left to right: whole part $\rightarrow$ tenths $\rightarrow$ hundredths $\rightarrow$ thousandths.

HOTS 1: Regular Polygon Geometry Perimeter & Sides
Each side of a regular polygon is $3.2\text{ cm}$ in length. The perimeter of the polygon is $19.2\text{ cm}$. How many sides does the polygon have? What is the name of the polygon?
Step-by-Step Solution
$$\text{Perimeter} = n \times \text{side length}$$ $$19.2 = n \times 3.2$$ $$n = \frac{19.2}{3.2} = \frac{192}{32} = \mathbf{6}$$

6 Mental Math Shortcuts for Decimals

1. Multiplying by 5:
Half the number, then multiply by 10.
$16.4 \times 5 = (16.4 \div 2) \times 10 = 8.2 \times 10 = \mathbf{82}$.
2. Multiplying by 25:
Divide by 4, then multiply by 100.
$3.6 \times 25 = (3.6 \div 4) \times 100 = 0.9 \times 100 = \mathbf{90}$.
3. Instant Eighths:
Memorize benchmark eighths: $\frac{1}{8} = 0.125,\; \frac{3}{8} = 0.375,\; \frac{5}{8} = 0.625,\; \frac{7}{8} = 0.875$.
4. Dividing by 5:
Double the number, then divide by 10.
$42.5 \div 5 = (42.5 \times 2) \div 10 = 85.0 \div 10 = \mathbf{8.5}$.
5. Subtraction from Whole Numbers:
For $10 - 3.47$: Whole becomes $9$, tenths from 9 ($9-4=5$), hundredths from 10 ($10-7=3$) $\implies \mathbf{6.53}$!
6. Trailing Zeros Comparison:
Never compare without equal decimal lengths: turn $0.8$ vs $0.78$ instantly into $0.80$ vs $0.78$ ($80 > 78$).

Top 7 Traps & Common Pitfalls

  • Trap 1: "Longer Decimal is Bigger": Believing $0.145 > 0.8$ because $145 > 8$. (Correction: $0.8 = 0.800 > 0.145$).
  • Trap 2: Aligning by Digits Instead of Points: In addition like $4.2 + 13.56$, aligning 2 under 6 instead of aligning decimal points.
  • Trap 3: Metric Conversion Scale Errors: Writing $5\text{ kg } 3\text{ g} = 5.3\text{ kg}$ instead of $5.003\text{ kg}$ ($1000\text{ g} = 1\text{ kg}$).
  • Trap 4: Decimal Point Shift in Division: Shifting the decimal point right when dividing instead of left ($25.4 \div 10 = 2.54$).
  • Trap 5: Counting Decimal Places in Products: Forgetting to count decimal places of BOTH factors: $0.2 \times 0.3 = 0.06$ (not $0.6$).
  • Trap 6: Dot Notation Confusion: Confusing time ($3.5\text{ hours} = 3\text{ hr } 30\text{ min}$, not $50\text{ min}$) or drops with decimals.
  • Trap 7: Forgetting Zero in Borrowing: In $7 - 0.05$, treating blank hundredths as $5$ instead of $10 - 5 = 5$ with borrowing ($6.95$).

Beyond Grade 7: Fascinating Decimals Preview

1. Why does $0.9999\dots = 1$?

Let $x = 0.9999\dots$

Multiply both sides by 10: $10x = 9.9999\dots$

Subtract the first equation from the second:
$$10x - x = 9.9999\dots - 0.9999\dots$$
$$9x = 9 \implies \mathbf{x = 1}$$

In mathematics, $0.\bar{9}$ is not just "close" to 1; it is identically equal to 1!

2. Repeating Decimals to Fractions:

Any repeating decimal is a rational number: $\frac{1}{3} = 0.\bar{3}$, $\frac{1}{7} = 0.\overline{142857}$.

3. Irrational Numbers:

Numbers like $\pi = 3.14159265\dots$ and $\sqrt{2} = 1.41421356\dots$ never terminate and never repeat. They cannot be written as a fraction $\frac{a}{b}$.

Question 5 NCERT Figure It Out • Concept Inquiry
Will a decimal number with more digits be greater than a decimal number with fewer digits?
Explanation & Mathematical Counter-Examples
❌ No, a decimal number with more digits is NOT necessarily greater.

Fundamental Mathematical Reason:
In whole numbers, more digits mean higher powers of ten (e.g., $1000 > 99$). But in decimals, digits after the point represent fractional parts (tenths, hundredths, thousandths) that decrease rapidly by powers of ten. The value is determined by comparing digits from left to right, starting with the highest place-value column.

Concrete Counter-Examples:
  1. $0.1234$ vs $0.5$: $0.1234$ has 4 decimal digits, while $0.5$ has only 1 decimal digit. Yet: $$0.1234 < 0.5 \quad (\text{since } 1\text{ tenth} < 5\text{ tenths})$$
  2. $0.0009$ vs $0.1$: $0.0009$ has 4 decimal digits, but $0.0009 < 0.1$.
  3. $1.2$ vs $0.9999$: $1.2$ has only 2 digits, while $0.9999$ has 4 digits, but $1.2 > 0.9999$ because $1 > 0$ in the ones column.

Question 46 2 Marks • Money Decimal
Find the decimal expression for $6\text{ rupees } 8\text{ paise}$ (in rupees).
Step-by-Step Mathematical Working
$$\begin{aligned} 1\text{ rupee} &= 100\text{ paise} \\ 8\text{ paise} &= \text{Rs. } \frac{8}{100} = \text{Rs. } 0.08 \\ 6\text{ rupees } 8\text{ paise} &= \text{Rs. } (6 + 0.08) = \mathbf{\text{Rs. } 6.08} \end{aligned}$$
⚠️ Common Student Mistake to Avoid:
Many students mistakenly write $6\text{ rupees } 8\text{ paise} = \text{Rs. } 6.8$. But $\text{Rs. } 6.8 = \text{Rs. } 6.80 = 6\text{ rupees } 80\text{ paise}$! Because $1\text{ rupee} = 100\text{ paise}$, single-digit paise must always take the hundredths place with a zero in the tenths place: $\mathbf{\text{Rs. } 6.08}$.
✅ Final Answer: $\mathbf{\text{Rs. } 6.08}$
Question 47 2 Marks • Multi-Fraction Simplification
Simplify the following sums:
(i) $1\dfrac{6}{7} + 11\dfrac{2}{5} + \dfrac{21}{5}$
(ii) $2\dfrac{2}{3} + 12\dfrac{2}{4} + 5\dfrac{1}{2}$
Step-by-Step Mathematical Working
(i) $1\dfrac{6}{7} + 11\dfrac{2}{5} + \dfrac{21}{5}$

Step 1: Combine like-denominator fractions ($\text{denominator } 5$):

$$11\frac{2}{5} + \frac{21}{5} = \frac{57}{5} + \frac{21}{5} = \frac{78}{5} = 15.6$$

Step 2: Add $1\frac{6}{7} = \frac{13}{7}$:

$$\frac{13}{7} + \frac{78}{5} = \frac{13 \times 5 + 78 \times 7}{35} = \frac{65 + 546}{35} = \frac{611}{35}$$

Step 3: Convert to mixed fraction:

$$611 \div 35 = 17\text{ with remainder } 16$$ $$\frac{611}{35} = \mathbf{17\frac{16}{35}} \approx \mathbf{17.457}$$
✅ Final Answer: $\mathbf{17\frac{16}{35}}$
(ii) $2\dfrac{2}{3} + 12\dfrac{2}{4} + 5\dfrac{1}{2}$

Step 1: Simplify the fraction $\frac{2}{4}$:

$$12\frac{2}{4} = 12\frac{1}{2}$$

Step 2: Add halves together:

$$12\frac{1}{2} + 5\frac{1}{2} = 12.5 + 5.5 = \mathbf{18}$$

Step 3: Add to $2\frac{2}{3}$:

$$18 + 2\frac{2}{3} = \mathbf{20\frac{2}{3}} = \frac{62}{3} \approx \mathbf{20.667}$$
✅ Final Answer: $\mathbf{20\frac{2}{3}}$ (or $\frac{62}{3}$)
