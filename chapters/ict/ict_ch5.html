The Silent, Text-Only Web & The Multimedia Explosion (1993 NCSA Mosaic)

Tier 1: Pre-Lesson Warm-Up • Historical Architecture
1993: When the Web First Got Eyes

When the World Wide Web debuted in 1991, it did not have a single picture. If you clicked a link to view a graphic, your computer opened an external software program in another window!

In February 1993, student programmers Marc Andreessen and Eric Bina at the University of Illinois invented the NCSA Mosaic web browser. They introduced a controversial, revolutionary tag: <img src="...">. For the very first time in human history, photographs and diagrams could appear inline alongside text. Within 12 months, web traffic surged by over 341,000%, sparking the dot-com era!

Why Doesn't HTML Store the Image?
Unlike Microsoft Word where images are pasted directly into the .docx file, HTML documents are pure plain-text files. The <img> tag does NOT hold image data; it merely holds a hyperlink address (the src attribute). The browser downloads the text file first, notices the image reference, and sends a second request across the network to fetch the graphic file!
The Pixel Compression Dilemma (JPG vs PNG)
An uncompressed 4K photo contains over 24 megabytes of raw numbers. On a slow mobile network, downloading that raw file takes 30 seconds! JPEG solves this using lossy cosine compression (discarding color details the human eye cannot detect), while PNG uses lossless compression for sharp text, logos, and alpha-transparency.

MOD 01

Significance of Lists in Web Design & List Architecture

Textbook pp. 72-73 • Core Concepts

In HTML, lists are essential structural elements used to group, associate, and format related pieces of information into clean, organized, and easily readable presentations.

Why Use Lists on Web Pages?

• Readability: Breaks dense text into digestible bulleted items.
• Navigation Menus: Almost every website navigation bar is constructed using an unordered list (<ul>) styled with CSS.
• Step-by-Step Instructions: Ordered lists guide users through sequential procedures (e.g. recipes, installation guides).

The 3 Types of HTML Lists

1. Unordered List (<ul>): Bulleted items without sequential ranking.
2. Ordered List (<ol>): Numbered items following a strict numerical or alphabetical sequence.
3. Definition / Description List (<dl>): Glossary terms paired with descriptive definitions.

MOD 02

Unordered (<ul>) vs Ordered (<ol>) Lists

Textbook pp. 73-75 • Tags & Attributes

Unordered List (<ul>)

Enclosed within <ul>...</ul>. Individual items are marked with <li>...</li>.
The type Attribute:
• disc: Solid black circle (Default!)
• circle: Hollow ring
• square: Solid square box
Note: 'rectangle' or 'triangle' are INVALID!

Ordered List (<ol>)

Enclosed within <ol>...</ol>.
The type Attribute:
• 1: Arabic numerals (1, 2, 3...) — Default!
• a / A: Lowercase/Uppercase letters
• i / I: Lowercase/Uppercase Roman numerals
The start Attribute: Specifies starting number (always an integer, e.g. start="5").
The reversed Attribute: Counts down in reverse order.

MOD 03

Definition Lists (<dl>) & Hierarchical Nested Lists

Textbook pp. 75-76 • Advanced Structuring

Definition / Description List (<dl>)

Unlike UL and OL, definition lists do not use bullet points or numbers. They are structured as term-description pairs:
• <dl>: Defines the definition list container.
• <dt>: Definition Term (the word/header being defined).
• <dd>: Definition Description (the indented explanation).
Ideal for glossaries, FAQs, and metadata specs.

Nested Lists (Lists Inside Lists)

A list placed inside a list item (<li>) of another parent list.
Rule: The child list must be nested inside the opening and closing <li> tag of the parent item.
Example: A multi-level table of contents or folder hierarchy.

MOD 04

Inserting Images with <img> & Graphic Formats

Textbook pp. 76-78 • Multimedia Tags

The <img> tag is an Empty Tag (no closing tag). It embeds images into the page.

Key <img> Attributes

• src: Source file path or URL (MANDATORY!).
• alt: Alternate text displayed if the image fails to load, and read aloud by screen readers for accessibility.
• width & height: Dimensions in pixels or percentages.
• border: Thickness of border around the image.

Web Graphic Formats

• JPEG / JPG: Best for photos with millions of subtle color gradients.
• PNG: Best for logos and graphics requiring transparency.
• GIF: Supports simple animations and 256 indexed colors.
• SVG: Scalable vector graphics that never lose sharpness.

MOD 05

Animated Text Tickers: The <marquee> Tag

Textbook p. 78 • Scrolling Text

<marquee> Attributes

• direction: left (default), right, up, down.
• behavior: scroll (continuous loop), slide (slides in and stops), alternate (bounces back and forth between edges).
• scrollamount: Speed of motion in pixels per step (e.g. scrollamount="10").
• loop: Number of times the animation executes (default is infinite).
Note: Deprecated in modern HTML5 in favor of CSS @keyframes, but still extensively tested in Class 7 CBSE exams!

MOD 06

Structuring Data with HTML Tables (<table>)

Textbook & Blueprint • 2D Data Grid

Core Table Tags

• <table>: Container for the entire table.
• <tr>: Table Row.
• <th>: Table Header (bold, centered text).
• <td>: Table Data cell (regular, left-aligned text).
• <caption>: Title header of the table.

Spanning & Spacing Attributes

• colspan="N": Merges a cell across N columns horizontally.
• rowspan="N": Merges a cell down N rows vertically.
• cellpadding: Space between cell border and cell content.
• cellspacing: Space between adjacent cells.
• CSS border-collapse: collapse; merges double borders into a clean single line!

MOD 08

Master Chapter Wrap-Up & Top 5 Exam Traps

Tier 3: Master Revision • 100% Exam Armor

"In A Nutshell" 6-Point Rapid Retention Sheet

3 List Types: <ul> (Unordered/Bulleted), <ol> (Ordered/Numbered), <dl> (Definition/Description with <dt> and <dd>).
UL Defaults: Defaults to disc. Valid types: disc, circle, square.
OL Attributes: type (1, a, A, i, I), start (always an integer number!), reversed (countdown sequence).
<img> Empty Tag: Requires src (path) and alt (accessibility text). Does NOT have a closing tag!
Table Cell Spanning: colspan merges columns horizontally. rowspan merges rows vertically.
Cell Padding vs Spacing: cellpadding is inner space between border & text. cellspacing is outer space between adjacent cells.

The Top 5 CBSE Exam Traps (Where Students Lose Marks)

Trap 1: Adding a Closing Tag to <img>
Writing <img src="pic.jpg"></img>. <img> is strictly an empty tag and has no closing companion.
Always write <img src="..." alt="...">.
Trap 2: Writing Letters in the 'start' Attribute
Writing <ol type="A" start="C">. The start attribute ONLY accepts numeric integers!
To start at 'C', write <ol type="A" start="3">!
Trap 3: Confusing Colspan with Rowspan
Using rowspan when trying to merge cells horizontally across columns.
COLSPAN = Columns (Horizontal). ROWSPAN = Rows (Vertical)!
Trap 4: Confusing Padding with Spacing
Mixing up cellpadding with cellspacing in table exam questions.
Padding = Inside the cell (border to text). Spacing = Between separate cells!
Trap 5: Invalid Unordered List Types
Answering "triangle" or "rectangle" for <ul type="...">.
Only three bullet types exist: disc, circle, and square!

ICT_CH05_020 OL Attributes: TYPE and START Medium • 4 Marks

What is the purpose of using TYPE and START attributes in an ordered list (<OL>)? Explain with examples.

View Model Answer & Code
1. TYPE Attribute:
• Purpose: Defines the numbering or lettering style for the list items.
• Supported Values: '1' (Arabic: 1, 2, 3), 'A' (Uppercase alphabet: A, B, C), 'a' (Lowercase alphabet: a, b, c), 'I' (Uppercase Roman: I, II, III), 'i' (Lowercase Roman: i, ii, iii).
• Default: If omitted, the default is '1'.
• Example: <ol type='A'> generates A., B., C.

2. START Attribute:
• Purpose: Specifies the initial numerical starting point for the list sequence.
• Rule: The value of 'start' must ALWAYS be an integer (Arabic number), even if the 'type' is set to Roman numerals or letters.
• Example: <ol type='A' start='4'> starts numbering from 'D' (since D is the 4th letter of the alphabet). <ol type='I' start='10'> starts from 'X'.
Teacher Rationale: Award 2 marks for TYPE attribute (purpose, all 5 options, syntax) and 2 marks for START attribute (purpose, integer rule, code example).

The <marquee> Tag:
The <marquee> tag is used in HTML to create scrolling text, animated tickers, or moving images across a webpage.

<ul> Unordered List

Creates bulleted items. Default bullet is disc. Valid values: disc, circle, square.

colspan="N" merges cells across N columns horizontally. rowspan="N" merges cells across N rows vertically.

Cellpadding vs Cellspacing

cellpadding is inner clearance (border to text). cellspacing is outer distance between table cells.
