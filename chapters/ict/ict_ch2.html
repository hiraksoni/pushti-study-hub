Advanced Features of Excel

Master data visualization with Excel charts, master the components of a chart, and learn how to organize, sort, and filter tabular datasets with mathematical precision.

Key Terms Glossary

Chart

A pictorial representation of worksheet data that enables quick visual comparison, pattern discovery, and trend analysis.

Chart Area

The total area containing the chart, all graphics, titles, legends, data labels, and the internal plot area.

Plot Area

The inner rectangular window bounded by the axes where the actual data markers and gridlines are plotted.

Data Series

A collection or related set of data points (values) derived from a single row or column of the spreadsheet.

Category Axis (X)

The horizontal axis representing the categories or textual labels of data being plotted.

Value Axis (Y)

The vertical axis used to measure and plot numerical values across the categories.

Legend

A key box displaying unique colors, patterns, or symbols assigned to differentiate each data series.

Gridlines

Horizontal and vertical reference lines extending across the plot area to make reading values precise.

Data Marker

An individual bar, slice, column, dot, or symbol that physically represents a specific numerical data value.

Sorting

The systematic arrangement of worksheet rows in ascending (A-Z, 1-9) or descending (Z-A, 9-1) order.

AutoFilter

A feature that temporarily hides unwanted rows and displays only records that satisfy specific filter criteria.

F11 Shortcut

The designated function key in Excel to instantly create a default chart on a new dedicated chart sheet.

Comprehensive Chart Types Taxonomy

Column Chart

Structure: Displays data using vertical rectangular bars.

Best Used For: Comparing values across discrete categories or showing change over short intervals of time.

Bar Chart

Structure: Displays data using horizontal rectangular bars.

Best Used For: Comparing items when category labels are lengthy or when visual space favors horizontal extension.

Line Chart

Structure: Connects individual data points with continuous lines.

Best Used For: Displaying continuous trends and fluctuations over equal intervals (days, months, years).

Pie Chart

Structure: A circular chart divided into proportional sectors/slices.

Best Used For: Showing proportional contribution of each item to a 100% whole (strictly handles 1 data series).

Doughnut Chart

Structure: Similar to a pie chart with a hollow center ring.

Best Used For: Comparing proportional parts of a whole across multiple data series simultaneously.

Area Chart

Structure: Line chart with filled color beneath the connecting lines.

Best Used For: Emphasizing the total magnitude and volume of change over time, not just the trend line.

Scatter (XY) Chart

Structure: Plots numerical values along both horizontal and vertical axes.

Best Used For: Scientific experiments, engineering data, and discovering correlation between two variables.

Surface Chart

Structure: 3D landscape mesh connecting data points across dimensions.

Best Used For: Finding optimum combinations between two sets of data across complex topographical models.

Core Operational Procedures in Excel

1. Inserting a Chart

  1. Select the cell range containing labels and numeric data.
  2. Click the Insert tab on the Ribbon.
  3. In the Charts group, click your preferred chart icon (e.g. Column or Pie).
  4. Choose the specific 2D or 3D subtype from the gallery.
  5. Quick Shortcut: Press F11 to generate an instant chart sheet!

2. Moving & Sizing

  1. Click on the chart border to select it.
  2. Under Chart Design tab $\rightarrow$ click Move Chart.
  3. Select New sheet (standalone sheet) or Object in (existing sheet).
  4. Click OK to relocate.
  5. Drag circular corner handles to resize proportionally.

3. Sorting Data

  1. Click any cell within the column to sort.
  2. Go to Home tab $\rightarrow$ Editing group $\rightarrow$ Sort & Filter.
  3. Click Sort A to Z (Ascending) or Sort Z to A (Descending).
  4. Custom Multi-Level: Open Data $\rightarrow$ Sort dialog, check "My data has headers", and click Add Level.

4. Filtering Data

  1. Click any cell in the data table.
  2. On Data (or Home) tab $\rightarrow$ click Filter. Drop-down arrows appear on headers.
  3. Click the arrow on the target column $\rightarrow$ check/uncheck criteria.
  4. Click OK. Non-matching rows hide temporarily.
  5. To Remove: Click Clear or toggle the Filter button off.

Q4.1 4 Marks
Explain the types of charts.
View Model Answer
Major Chart Types in Excel:
  1. Column Chart: Uses vertical bars to compare data categories over time.
  2. Bar Chart: Uses horizontal bars to compare discrete items; especially effective for long labels.
  3. Line Chart: Connects points with lines to illustrate continuous trends and patterns at equal intervals.
  4. Pie Chart: A circular chart divided into slices showing the proportion of each value to the whole (1 data series only).
  5. Area Chart: Similar to line charts with filled areas underneath to highlight the volume of change.
  6. Scatter (XY) Chart: Shows relationships between two sets of numbers on coordinate axes.
Q4.2 4 Marks
Explain the elements of a chart.
View Model Answer
Key Elements of an Excel Chart:
  • Chart Area: Encompasses the entire chart window and all child elements.
  • Plot Area: The inner rectangular region bounded by axes where data is drawn.
  • Category Axis (X): Horizontal axis containing category names.
  • Value Axis (Y): Vertical axis calibrated with numeric measurement values.
  • Data Series: Related data points originating from a single row or column.
  • Data Marker: Individual physical bars, slices, or dots representing data values.
  • Legend: Key box identifying the color/pattern of each data series.
  • Gridlines: Horizontal or vertical lines providing coordinate alignment.
Q4.3 4 Marks
Explain the steps to move the chart to another location.
View Model Answer
Steps to Move a Chart:
  1. Click on the chart to select it. The Chart Tools tab appears on the Ribbon.
  2. Click the Design (or Chart Design) contextual tab.
  3. In the Location group, click the Move Chart button.
  4. In the Move Chart dialog box:
    • Choose New sheet to place the chart on its own dedicated sheet.
    • Or choose Object in and select an existing sheet from the dropdown.
  5. Click OK to confirm.
Q4.4 4 Marks
Write the steps to apply sorting on a worksheet.
View Model Answer
Steps to Apply Sorting:
  1. Select the data range including the column headers.
  2. Navigate to the Data tab (or Home tab $\rightarrow$ Editing group).
  3. Click the Sort button in the Sort & Filter group.
  4. In the Sort dialog box:
    • Ensure "My data has headers" is checked.
    • Under Column, select the primary column to sort by.
    • Under Sort On, select Cell Values.
    • Under Order, choose A to Z (Ascending) or Z to A (Descending).
    • (Optional) Click Add Level to add secondary sorting columns.
  5. Click OK to execute the sort.
Q4.5 4 Marks
How can filters once applied be removed?
View Model Answer
Removing Applied Filters:
  • To Clear Filter from a Single Column: Click the Filter icon next to the column heading, then select "Clear Filter From [Column Name]".
  • To Clear All Active Filters: Go to the Data tab (or Home tab) and click the Clear button in the Sort & Filter group. All hidden rows immediately reappear.
  • To Turn Off AutoFilter Completely: Click the Filter toggle button in the Sort & Filter group. The dropdown arrows will be removed from all headers.

Section D: Sorting with Practical Example (Worksheet 2 p. 40)

WS D 3 Marks
What do you understand by sorting? Explain with an example.
View Model Answer & Example
1. Understanding Sorting:
Sorting is the feature in Excel that rearranges rows of data in a defined order according to values in one or more columns. It can be performed in two directions:
  • Ascending Order: Arranges text alphabetically from A to Z, numbers from smallest to largest (0 to 9), and dates from oldest to newest.
  • Descending Order: Arranges text from Z to A, numbers from largest to smallest (9 to 0), and dates from newest to oldest.
2. Concrete Example:
Consider a class marksheet with student scores:
Original: [Amrita: 45, Gautam: 24, Hemant: 34, Ishaan: 43]
If we apply Ascending Sort on the Marks column, Excel rearranges the records to:
Ascending: [Gautam: 24, Hemant: 34, Ishaan: 43, Amrita: 45]
This immediately highlights the lowest and highest marks and simplifies ranking and report card preparation.
