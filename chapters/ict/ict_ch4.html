Module 1: The <BODY> Tag & Canvas Attributes

Textbook pp. 56-57

The <body> tag defines the main visible canvas of an HTML document. All content visible to the user—headings, paragraphs, images, tables, and hyperlinks—resides inside this tag. It is a container tag (<body>...</body>).

Attribute Purpose / Description Syntax & Sample Values Default Value
BGCOLOR Specifies the solid background color of the web page. <body bgcolor="yellow"> or hex "#FFFF00" White
BACKGROUND Specifies the path or URL of an image file to be used as wallpaper. <body background="images/bg.jpg"> None (Transparent)
TEXT Sets the default foreground color for all normal body text on the page. <body text="navy"> or hex "#000080" Black
LEFTMARGIN Sets the blank space (margin) between the left edge of the browser window and page content (in pixels). <body leftmargin="60"> Browser default (~8px-10px)
TOPMARGIN Sets the blank space (margin) between the top edge of the browser window and page content (in pixels). <body topmargin="50"> Browser default (~10px-15px)
LINK Sets the display color of an unvisited hyperlink (link not yet clicked). <body link="blue"> Blue
ALINK Sets the color of an active hyperlink (the instant the user clicks/holds it). <body alink="red"> Red
VLINK Sets the color of a visited hyperlink (link already visited by user). <body vlink="purple"> Purple / Violet
Exam Trap Alert: Do not confuse BGCOLOR (which accepts color names/hex codes) with BACKGROUND (which takes an image file path). Remember that ALINK defaults to Red and VLINK defaults to Purple, never vice-versa!

Module 2: Structural & Text Formatting Tags

Textbook pp. 58-59

Paragraph Tag <P> Container Tag

Used to structure text into distinct paragraphs. The browser automatically introduces a blank line before and after the paragraph.

Supported Attribute: ALIGN
• align="left": Aligns text to left margin (Default).
• align="center": Centers text horizontally.
• align="right": Aligns text to right margin.
• align="justify": Aligns text to both left and right margins evenly.

Example: <p align="center">Welcome to Pushti Study Hub</p>

Line Break Tag <BR> Empty / Unpaired Tag

Used to end the current line immediately and jump the cursor to the next line. Unlike <p>, it does not insert empty blank vertical space between lines.

Key Characteristics:
• Void element: Has no closing tag (</br> does not exist).
• Has no attributes in standard HTML.
• Useful for poetry, addresses, and multi-line titles.

Example: Pushti Soni<br>Class 7 CBSE<br>ICT Chapter 4

Horizontal Centering <CENTER> Container Tag

The <center> tag centers all enclosed text, images, or elements horizontally on the screen.

Example: <center><h1>Annual Sports Day</h1></center>

Note: Deprecated in HTML5 in favor of CSS text-align: center; or flexbox.

HTML Comments Non-Executable Notes

Comments are developer notes placed in the HTML source code. They are completely ignored by the web browser and never rendered on the screen.

Standard Syntax:
<!-- This is a standard HTML comment -->

Obsolete Tag (Textbook Note):
<comment>Old comment syntax</comment> (Obsolete in modern HTML5).

Module 3: Character & Physical Formatting Tags

Textbook pp. 59-61

The <FONT> Tag & Its 3 Attributes Container Tag

Used to alter the typeface, color, and size of enclosed text. It supports three primary attributes:

Attribute Function Accepted Values Example
FACE Specifies the font family / typeface. Font family name: Arial, Comic Sans MS, Times New Roman, Courier New <font face="Arial">Text</font>
COLOR Specifies the font color. Named colors (red, blue, green) or hexadecimal (#FF0000) <font color="darkblue">Text</font>
SIZE Specifies the font size. Numeric values from 1 to 7 (Default is 3, where 1 is smallest and 7 is largest) <font size="5">Text</font>

Physical Character Tags Container Tags

• Bold: <b>...</b> makes text bold.
• Italic: <i>...</i> inclines text in italics.
• Underline: <u>...</u> draws a solid line underneath text.

Nesting Example:
<b><i><u>Important Examination Announcement</u></i></b>

Subscript vs Superscript Math & Science

• Subscript <SUB>: Displays characters slightly below the baseline in a smaller font size.
Usage: Chemical formulae like Water (\(\text{H}_2\text{O}\)) or Sulphuric Acid (\(\text{H}_2\text{SO}_4\)):
H<sub>2</sub>SO<sub>4</sub>

• Superscript <SUP>: Displays characters slightly above the baseline in a smaller font size.
Usage: Mathematical powers and equations like \((a+b)^2\) or Pythagoras theorem:
(Hypotenuse)<sup>2</sup> = (Side1)<sup>2</sup> + (Side2)<sup>2</sup>

Module 4: Introduction to CSS & Architecture

Textbook pp. 60-62

What is CSS? Definition

CSS stands for Cascading Style Sheets.
It is a style sheet language designed to control the presentation, formatting, and layout of HTML web pages. While HTML specifies the structure and content, CSS defines the visual presentation (colors, fonts, margins, positioning, and responsive layouts).

Historical Timeline W3C Standard

• Proposed: On October 10, 1994 by Håkon Wium Lie while working with Tim Berners-Lee at CERN.
• Standardized: In December 1996, the World Wide Web Consortium (W3C) officially published the CSS1 Recommendation.
• Governance: Actively maintained and updated by the W3C CSS Working Group.

Four Major Advantages of Using CSS (Textbook pp. 61-62)

1. Saves Time Code Reuse

You can write CSS once and reuse the exact same stylesheet across multiple HTML elements or hundreds of web pages. Instead of repeating formatting attributes on every single tag, one CSS rule styles them all simultaneously.

2. Easy Maintenance Separation of Concerns

Separates content from visual styling. To execute a global redesign across an entire website with thousands of pages, a web developer simply modifies a few lines in one centralized CSS file, and all pages update instantly.

3. Fast Webpage Loading Browser Caching

When using external CSS, the browser downloads the .css file only once and caches it locally. Subsequent pages load substantially faster, drastically cutting bandwidth usage and server load.

4. Superior Styles & Printer-Friendly Typography & Media

CSS offers a vastly richer palette of typographic and visual styling properties than archaic HTML tags. Furthermore, it allows defining dedicated print stylesheets to format documents cleanly for physical printers.

Module 5: CSS Rule Syntax & Anatomy

Textbook pp. 62-63

A CSS rule-set consists of two fundamental components: a Selector and a Declaration Block.

h1 {
  color: blue;
  font-size: 24px;
  text-align: center;
}
▲ Selector  |  ▲ { } Declaration Block  |  ▲ Property  |  ▲ Value

1. The Selector

Points to the HTML element you want to style. It can be any HTML tag (e.g., h1, p, body, table), a class, or an ID.

2. The Declaration Block

Enclosed inside curly braces { }. It contains one or more declarations separated by semicolons (;).
Each declaration includes a CSS Property and a Value separated by a colon (:).

CSS Comments Syntax: Comments in CSS are written inside /* and */. Everything between them is ignored by the browser:
/* This is a single or multi-line CSS comment */

Module 6: The Three Types of CSS (Linking CSS to HTML)

Textbook pp. 63-65
Method Where it is Written Syntax & Code Example Scope & Purpose Advantages & Disadvantages
1. Inline Style Sheet Directly inside the opening HTML tag using the style attribute. <h1 style="color:red; font-size:24px;">Heading</h1> Affects only that single HTML element. ❌ Inefficient: Style declarations must be repeated for every element; mixes presentation with content.
2. Internal / Embedded CSS Inside the <style>...</style> container tag in the <head> section. <head>
 <style>
  p { color: navy; }
 </style>
</head> 		Applies to all matching elements across that single webpage. ✔ Convenient for single pages. ❌ Cannot be reused across multiple HTML files.
3. External Style Sheet In a standalone file with a .css extension, linked via <link> inside <head>. <head>
 <link rel="stylesheet"
  type="text/css"
  href="mystyle.css">
</head> 		Controls the appearance of an entire multi-page website. ✔ Best method for websites: Reusable, cached by browsers, enables instant site-wide redesigns.

Module 7: CSS Background Properties

Textbook pp. 65-66
Property Description Accepted Values & Options Sample Declaration
background-color Sets the background color of an element. Color name (cyan), Hex (#00FFFF), RGB, or RGBA with opacity. body { background-color: lightcyan; }
background-image Sets a graphic file as the element's background. url("image_path") body { background-image: url("flower.png"); }
background-position Sets the initial starting position of the background image. Keywords (top left, center, bottom right), percentages, or coordinates (x y in px). Default is 0 0. body { background-position: center top; }
background-repeat Controls how the background image repeats (tiles) across the screen. • repeat: Tiles horizontally and vertically (Default).
• repeat-x: Tiles horizontally only.
• repeat-y: Tiles vertically only.
• no-repeat: Displays image only once without repeating. 		body { background-repeat: no-repeat; }
RGBA Opacity Note (Textbook p. 65): In CSS3, you can use rgba(red, green, blue, alpha) where the alpha parameter defines transparency from 0.0 (fully transparent) to 1.0 (completely opaque). Example: background-color: rgba(255, 0, 0, 0.5);.

Module 8: CSS Typography & Font Properties

Textbook pp. 66-67
Property Purpose Accepted Values Example
font-family Specifies the typeface for text. Family names (Arial, Courier New) and Generic Fallback families (serif, sans-serif, monospace, cursive, fantasy). p { font-family: "Courier New", monospace; }
font-style Controls font posture. normal, italic, oblique h2 { font-style: italic; }
font-variant Renders text in small capital letters. normal, small-caps h3 { font-variant: small-caps; }
font-weight Controls boldness/thickness. normal, bold, bolder, lighter, or numeric 100 to 900. p.bold { font-weight: bold; }
font-size Defines text height. Units like px (pixels), pt (points), %, or keywords (small, medium, large). p { font-size: 16px; }
font (Shorthand) Sets all font properties in a single line. Order: font-style font-variant font-weight font-size font-family; p { font: italic bold 16px Arial, sans-serif; }

Constantia is a family name, NOT a generic family!

Module 9: Evolution of Web Standards & The CSS Cascade

Textbook p. 68

HTML5 Deprecation & Separation of Concerns

In the early days of HTML (early 1990s), tags like <font>, <center>, and presentational attributes like bgcolor, text, and background were used for styling.

Modern Standard:
HTML5 strictly deprecates presentational HTML elements in favor of the Separation of Concerns principle:
• HTML: Semantic Structure & Content
• CSS: Visual Layout & Aesthetics
• JavaScript: Logic & Interactivity

Why is it called "Cascading"? (Priority Order)

When multiple conflicting CSS rules target the exact same HTML element, the browser applies styles based on a strict precedence hierarchy called the Cascade Waterfall:

1. Inline CSS (Highest Priority - Overrides everything else)
2. Internal Style Sheet (Medium Priority - Declared in <head>)
3. External Style Sheet (Base styles across whole site)
4. Browser Default Styles (Lowest Priority)

Q5. Long Answer Questions (2 × 4M = 8 Marks)

8 Marks
Q5.1 • 4M
1. Explain the three types of CSS (Inline, Internal, and External) and state which is best for styling a multi-page website with reasons.
View Model Answer & Rubric

Three Types of CSS:

1. Inline CSS: Applied directly inside an individual HTML element using the style attribute (e.g. <h1 style="color:red;">). Only affects that specific element; inefficient for reuse.

2. Internal CSS: Declared inside the <style> tag within the <head> section. Formats all elements on that single page.

3. External CSS: Stored in an external file with a .css extension and linked using <link rel="stylesheet" href="style.css"> in the <head>.

Best Method for Websites: External CSS is the best because:
• A single stylesheet standardizes formatting across thousands of web pages.
• Updating that single file executes a site-wide redesign instantly.
• Web browsers cache external CSS files, resulting in significantly faster loading speeds.

Rubric: 1M for each type (3M) + 1M for External recommendation & reasons

Enrichment • Historical Trivia & HOTS Challenges

4 Deep Dive Questions
Trivia 1 • 1M
Who created HTML and when?
View Answer

HTML was created by Sir Tim Berners-Lee in late 1991 while working at CERN in Geneva, Switzerland. It was officially released to the public in 1995.

Trivia 2 • 1M
Who proposed CSS and when?
View Answer

CSS was proposed by Norwegian computer scientist Håkon Wium Lie on October 10, 1994, while collaborating with Tim Berners-Lee at CERN/W3C. W3C officially standardized CSS1 in December 1996.

Trivia 3 • 1M
Why is CSS called "Cascading"?
View Answer

When multiple contradictory styles target an element, rules "cascade" down like a waterfall from highest to lowest priority: Inline > Internal > External > Browser Default.

HOTS Challenge • 3M
A student wrote: <body bgcolor="cyan" text="navy"> in HTML, and also added an Internal CSS rule: body { background-color: yellow; color: darkred; }. Which colors will the browser display, and why?
View HOTS Solution & Explanation

Result: The web page will display a Yellow background with Dark Red text.

Reason: Modern web browsers prioritize CSS rules over legacy HTML presentational attributes (bgcolor, text). CSS styles override obsolete HTML tag attributes.
