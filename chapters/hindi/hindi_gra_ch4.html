व्याकरण पाठ 4: उपसर्ग एवं प्रत्यय

प्रस्तुत अध्याय में शब्द रचना के दो प्रमुख घटकों—उपसर्ग और प्रत्यय का सर्वांगीण, प्रामाणिक और गहन विश्लेषण किया गया है। उपसर्गों की परिभाषा, मूल शब्दों पर उनके उत्कर्षपरक एवं निषेधात्मक प्रभाव तथा तीनों स्रोतों (संस्कृत/तत्सम, हिंदी/तद्भव, उर्दू-फ़ारसी/आगत) का तालिकाबद्ध अध्ययन प्रस्तुत है। साथ ही प्रत्यय की परिभाषा, कृत् प्रत्यय (कृदंत) और तद्धित प्रत्यय (तद्धितांत) के भेद, दो प्रत्ययों का एक साथ प्रयोग तथा उपसर्ग व प्रत्यय के उभयनिष्ठ प्रयोग की विस्तृत रूपरेखा संपूर्ण अभ्यास प्रश्नों सहित संकलित है।

शब्द रचना एवं उपसर्ग की अवधारणा (Word Formation & Prefix)

भाषा में नए शब्दों के निर्माण की प्रक्रिया को शब्द रचना कहते हैं। इसमें मूल शब्दों के पूर्व या अंत में शब्दांश जोड़कर नए सार्थक शब्द गढ़े जाते हैं।

• उपसर्ग की परिभाषा: वे शब्दांश जो किसी मूल शब्द के पहले (पूर्व में) जुड़कर उसके अर्थ में विशेषता या परिवर्तन ला देते हैं, 'उपसर्ग' कहलाते हैं।

उदाहरण (हार शब्द में भिन्न उपसर्गों का प्रभाव):
- प्र + हार = प्रहार (चोट करना)
- उप + हार = उपहार (भेंट/उपहार)
- वि + हार = विहार (घूमना/भ्रमण)
- सम् + हार = संहार (विनाश करना)
- आ + हार = आहार (भोजन)

उपसर्गों के दो प्रमुख कार्य / प्रभाव (Two Functional Effects of Prefixes)

उपसर्ग मूल शब्दों के साथ जुड़कर मुख्यतः दो प्रकार के अर्थगत परिवर्तन करते हैं:
१. उत्कर्षपरक (भाव की वृद्धि या सकारात्मकता बढ़ाना): मूल शब्द के अर्थ में विशिष्टता, श्रेष्ठता या तीव्रता लाना; जैसे—बल -> प्रबल, मान -> सम्मान, ज्ञान -> विज्ञान।
२. निषेधात्मक (विपरीतार्थक या अभाव का बोध कराना): मूल शब्द के अर्थ का विलोम बनाना या अभाव प्रकट करना; जैसे—ज्ञान -> अज्ञान, यश -> अपयश, पूर्ण -> अपूर्ण, मान -> अपमान।

उपसर्गों के तीन मुख्य स्रोत एवं भेद (Three Sources of Prefixes)

हिंदी भाषा में प्रयुक्त होने वाले उपसर्गों को उनके भाषाई स्रोत के आधार पर तीन वर्गों में बाँटा गया है:

१. संस्कृत के उपसर्ग (तत्सम उपसर्ग): ये संस्कृत से ज्यों-के-त्यों हिंदी में आए हैं।
• अति (अधिक/परे): अत्यंत, अत्याचार, अतिरिक्त, अत्यधिक
• अधि (ऊपर/श्रेष्ठ): अधिकार, अधिपति, अध्यक्ष, अधिष्ठाता
• अनु (पीछे/समान): अनुवाद, अनुशासन, अनुकरण, अनुरूप
• अप (बुरा/हीन): अपमान, अपशब्द, अपराध, अपयश
• अभि (सामने/पास): अभिमान, अभिनेता, अभिलाषा, अभिभाषण
• अव (हीन/बुरा): अवनति, अवगुण, अवतार, अवशेष
• आ (तक/समेत): आजीवन, आमरण, आरक्षण, आगमन
• उत्/उद् (ऊपर/श्रेष्ठ): उत्कर्ष, उत्साह, उन्नति, उत्पत्ति
• उप (छोटा/समीप): उपवन, उपकार, उपनाम, उपदेश
• दुर्/दुष् (बुरा/कठिन): दुर्गुण, दुर्दशा, दुर्घटना, दुर्लभ, दुष्कर्म
• नि (बिना/नीचे): निवास, नियम, निबंध, निदेशक
• निर्/निस् (बिना/रहित): निर्दोष, निर्बल, निर्धन, निर्भय, निश्चय
• परा (उलटा/पीछे): पराजय, पराभव, पराक्रम, परामर्श
• परि (चारों ओर): परिवार, परिश्रम, परिवर्तन, परिणाम
• प्र (अधिक/आगे): प्रबल, प्रगति, प्रयोग, प्रकाश
• प्रति (प्रत्येक/विरुद्ध): प्रतिदिन, प्रतिकूल, प्रतिरोध, प्रतिध्वनि
• वि (विशेष/भिन्न): विदेश, विज्ञान, विशेष, विभाग
• सम् (अच्छा/पूर्ण): सम्मान, सम्मेलन, संपर्क, संसार
• स्व (अपना): स्वदेश, स्वतंत्र, स्वराज, स्वभाव

२. हिंदी के उपसर्ग (तद्भव उपसर्ग): ये संस्कृत के तत्सम उपसर्गों से विकसित होकर तद्भव रूप में प्रचलित हुए हैं।
• अ (अभाव/निषेध): अछूत, अटल, अमर, अगम
• अन (अभाव): अनहोनी, अनपढ़, अनजान, अनमोल
• अध (आधा): अधपका, अधमरा, अधजला, अधखिला
• कु (बुरा): कुपुत्र, कुमार्ग, कुसंग, कुरूप
• नि (रहित): निडर, निकम्मा, निहत्था, निधड़क
• स/सु (अच्छा/सहित): सपूत, सजग, सुपुत्र, सुगम

३. उर्दू-फ़ारसी के उपसर्ग (आगत उपसर्ग): ये विदेशी भाषाओं से हिंदी में समाहित हुए हैं।
• कम (थोड़ा/हीन): कमजोर, कमअक्ल, कमउम्र
• गैर (भिन्न/बिना): गैरहाज़िर, गैरकानूनी, गैरसरकारी
• ना (नहीं/अभाव): नालायक, नादान, नापसंद, नाबालिग
• बद (बुरा): बदनाम, बदचलन, बदबू, बदमाश
• बे (बिना): बेकसूर, बेईमान, बेचैन, बेअकल
• ला (बिना/रहित): लाचार, लावारिस, लाजवाब, लापरवाह
• हम (समान/साथी): हमदर्द, हमसफ़र, हमशक्ल, हमउम्र
• हर (प्रत्येक): हरएक, हरपल, हरदिन, हरवक्त

प्रत्यय की अवधारणा एवं भेद (Concept & Classification of Suffixes)

• प्रत्यय की परिभाषा: वे शब्दांश जो किसी शब्द के अंत में जुड़कर उसके अर्थ में परिवर्तन या विशेषता ला देते हैं, 'प्रत्यय' कहलाते हैं। जैसे—दया + आलू = दयालु, भारत + ईय = भारतीय, लिख + आई = लिखाई।

प्रत्यय के दो मुख्य भेद होते हैं:
१. कृत् प्रत्यय (Krut Pratyay): जो प्रत्यय धातुओं (क्रिया के मूल रूपों) के अंत में जुड़कर नए संज्ञा अथवा विशेषण शब्दों का निर्माण करते हैं, वे 'कृत् प्रत्यय' कहलाते हैं। इनसे बनने वाले शब्द 'कृदंत' कहलाते हैं।
उदाहरण:
- आई: पढ़ + आई = पढ़ाई, लिख + आई = लिखाई, चढ़ + आई = चढ़ाई
- आऊ: बिक + आऊ = बिकाऊ, टिक + आऊ = टिकाऊ, चल + आऊ = चलाऊ
- आक: तैर + आक = तैराक
- आकू: पढ़ + आकू = पढ़ाकू, लड़ + आकू = लड़ाकू
- आन: उड़ + आन = उड़ान, थक + आन = थकान, उठ + आन = उठान
- आवट: लिख + आवट = लिखावट, बन + आवट = बनावट, सज + आवट = सजावट
- आहट: घबरा + आहट = घबराहट, चिल्ला + आहट = चिल्लाहट
- ना: पढ़ + ना = पढ़ना, लिख + ना = लिखना
- नी: ओढ़ + नी = ओढ़नी, फूँक + नी = फूँकनी
- हार: होन + हार = होनहार, पालन + हार = पालनहार
- वाला: पढ़नेवाला, रखनेवाला

२. तद्धित प्रत्यय (Taddhit Pratyay): जो प्रत्यय संज्ञा, सर्वनाम अथवा विशेषण शब्दों के अंत में जुड़कर नए शब्द बनाते हैं, वे 'तद्धित प्रत्यय' कहलाते हैं। इनसे बनने वाले शब्द 'तद्धितांत' कहलाते हैं।
उदाहरण:
(क) संज्ञा से संज्ञा/विशेषण:
- आर: लोहा + आर = लुहार, सोना + आर = सुनार
- इया: डिब्बा + इया = डिबिया, खाट + इया = खटिया
- ई: पहाड़ + ई = पहाड़ी, खेत + ई = खेती
- एरा: चाचा + एरा = चचेरा, मामा + एरा = ममेरा
- दार: दुकान + दार = दुकानदार, हवा + दार = हवादार
- पन: बच्चा + पन = बचपन, लड़का + पन = लड़कपन
- पा: बूढ़ा + पा = बुढ़ापा, मोटा + पा = मोटापा
- इक: दिन + इक = दैनिक, समाज + इक = सामाजिक, भूत + इक = भौतिक
- ईला: चमक + ईला = चमकीला, रस + ईला = रसीला
- वान/मान: धन + वान = धनवान, बुद्धि + मान = बुद्धिमान
(ख) सर्वनाम से:
- पन: अपना + पन = अपनापन, पराया + पन = परायापन
- कार: अहम् + कार = अहंकार
(ग) विशेषण से संज्ञा:
- आई: अच्छा + आई = अच्छाई, बुरा + आई = बुराई, चतुर + आई = चतुराई
- आहट: कड़वा + आहट = कड़वाहट, चिकना + आहट = चिकनाहट
- ता: सुंदर + ता = सुंदरता, योग्य + ता = योग्यता, महान + ता = महानता
- पन: अंधा + पन = अंधापन, पीला + पन = पीलापन
- ई: गर्म + ई = गर्मी, सर्द + ई = सर्दी

विशिष्ट शब्द संरचनाएँ (Dual Affixes & Simultaneous Prefix-Suffix Usage)

१. दो प्रत्ययों का एक साथ प्रयोग: कुछ शब्दों में एक साथ दो प्रत्यय जुड़कर नए शब्द बनाते हैं;
- नीति + इक + ता = नैतिकता
- भारत + ईय + ता = भारतीयता
- मानव + ईय + ता = मानवीयता
- भूत + इक + ता = भौतिकता
- राष्ट्र + ईय + ता = राष्ट्रीयता

२. उपसर्ग एवं प्रत्यय का एक साथ प्रयोग: कुछ शब्दों में एक ही मूल शब्द के पहले उपसर्ग और अंत में प्रत्यय दोनों जुड़ते हैं;
- अ + मानव + ईय = अमानवीय
- अप + मान + इत = अपमानित
- अ + विश्वास + ई = अविश्वासी
- स + फल + ता = सफलता
- दुर् + बल + ता = दुर्बलता
- अभि + मान + ई = अभिमानी
- परि + पूर्ण + ता = परिपूर्णता
- बे + चैन + ई = बेचैनी
- उप + कार + ई = उपकारी

व्याकरणिक शब्दावली व प्रामाणिक परिभाषाएँ

कठिन शब्दों व पारिभाषिक शब्दों के अंग्रेज़ी अनुवाद व सरल अर्थ

उपसर्ग (Prefix)

वे शब्दांश जो मूल शब्द के आरंभ (पूर्व) में जुड़कर उसके अर्थ में विशेषता या परिवर्तन लाते हैं।

प्रत्यय (Suffix)

वे शब्दांश जो मूल शब्द के अंत में जुड़कर नए शब्द बनाते हैं या अर्थ में विशेषता लाते हैं।

मूल शब्द (Root Word)

वह मौलिक और सार्थक शब्द जिसमें कोई उपसर्ग या प्रत्यय नहीं जुड़ा होता।

कृत् प्रत्यय (Primary Suffix)

जो प्रत्यय धातुओं (क्रिया के मूल रूपों) के अंत में जुड़कर संज्ञा या विशेषण शब्द बनाते हैं।

कृदंत (Participle / Verbal Derivative)

कृत् प्रत्यय के योग से निर्मित होने वाले शब्द।

तद्धित प्रत्यय (Secondary Suffix)

जो प्रत्यय संज्ञा, सर्वनाम अथवा विशेषण शब्दों के अंत में जुड़कर नए शब्द बनाते हैं।

तद्धितांत (Secondary Derivative)

तद्धित प्रत्यय के योग से निर्मित होने वाले नए शब्द।

आदर्श उत्तर: उपसर्ग मूल शब्द के आरंभ (पहले / पूर्व) में जुड़ते हैं।
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २३ के अनुसार उपसर्ग वे शब्दांश हैं जो मूल शब्द के पूर्व में जुड़कर उसके अर्थ में नवीन विशेषता या परिवर्तन लाते हैं।
आदर्श उत्तर: प्रत्यय मुख्य रूप से दो प्रकार के होते हैं:
१. कृत् प्रत्यय (क्रिया/धातु के अंत में लगने वाले)
२. तद्धित प्रत्यय (संज्ञा, सर्वनाम या विशेषण के अंत में लगने वाले)
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २५ के अनुसार प्रत्यय के दो भेद हैं—कृत् प्रत्यय तथा तद्धित प्रत्यय।
आदर्श उत्तर: वे शब्दांश जो किसी मूल शब्द के पहले (पूर्व में) जुड़कर उसके अर्थ में विशेषता या परिवर्तन ला देते हैं, 'उपसर्ग' कहलाते हैं।
उदाहरण:
• 'हार' मूल शब्द में भिन्न उपसर्ग जोड़ने पर:
- प्र + हार = प्रहार (चोट)
- उप + हार = उपहार (भेंट)
- वि + हार = विहार (भ्रमण)
- आ + हार = आहार (भोजन)
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २३ के आधार पर उपसर्ग की परिभाषा और सोदाहरण व्याख्या।
आदर्श उत्तर: कृत् और तद्धित प्रत्यय में मुख्य अंतर:
१. कृत् प्रत्यय: ये क्रिया के मूल रूप अर्थात् धातुओं के अंत में जुड़कर नए संज्ञा या विशेषण शब्द बनाते हैं; जैसे—पढ़ + आई = पढ़ाई, लिख + आवट = लिखावट। इनसे बने शब्दों को 'कृदंत' कहते हैं।
२. तद्धित प्रत्यय: ये क्रिया से भिन्न संज्ञा, सर्वनाम अथवा विशेषण शब्दों के अंत में जुड़कर नए शब्द बनाते हैं; जैसे—मानव + ता = मानवता, अपना + पन = अपनापन, चतुर + आई = चतुराई। इनसे बने शब्दों को 'तद्धितांत' कहते हैं।
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २५ पर दोनों प्रत्ययों का पारस्परिक अंतर स्पष्ट रूप से परिभाषित है।
आदर्श उत्तर: (क) बद -> बदनाम, बदमाश (या बदबू)
(ख) कु -> कुपुत्र, कुमार्ग (या कुसंग)
(ग) नि -> निडर, निकम्मा (या निहत्था)
(घ) प्र -> प्रबल, प्रगति (या प्रयोग)
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २८ अभ्यास ख.२ से उपसर्ग शब्द निर्माण।
आदर्श उत्तर: (क) इक -> दैनिक, सामाजिक (या भौतिक)
(ख) ईला -> चमकीला, रसीला (या सुरीला)
(ग) ता -> सुंदरता, मानवता (या योग्यता)
(घ) आऊ -> बिकाऊ, टिकाऊ (या चलाऊ)
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २८ अभ्यास ख.३ से प्रत्यय शब्द निर्माण।
आदर्श उत्तर: (क) अपमानित = अप (उपसर्ग) + मान (मूल शब्द) + इत (प्रत्यय)
(ख) अभिमानी = अभि (उपसर्ग) + मान (मूल शब्द) + ई (प्रत्यय)
(ग) अविश्वासी = अ (उपसर्ग) + विश्वास (मूल शब्द) + ई (प्रत्यय)
(घ) सफलता = स (उपसर्ग) + फल (मूल शब्द) + ता (प्रत्यय)
(ङ) दुर्बलता = दुर् (उपसर्ग) + बल (मूल शब्द) + ता (प्रत्यय)
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २८ अभ्यास ख.४ के अंतर्गत उपसर्ग एवं प्रत्यय का एक साथ विच्छेदन।
आदर्श उत्तर: उपसर्ग एवं प्रत्यय से निर्मित ८ शब्द:
१. अप + यश = अपयश (उपसर्ग)
२. दुर् + जन = दुर्जन (उपसर्ग)
३. वि + ज्ञान = विज्ञान (उपसर्ग)
४. सु + जन = सुजन (उपसर्ग)
५. लिख + आई = लिखाई (कृत् प्रत्यय)
६. पढ़ + आई = पढ़ाई (कृत् प्रत्यय)
७. मानव + ता = मानवता (तद्धित प्रत्यय)
८. सुंदर + ता = सुंदरता (तद्धित प्रत्यय)
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २९ गतिविधि घ।
आदर्श उत्तर: दो प्रत्ययों के एक साथ प्रयोग के तीन उदाहरण:
१. नैतिकता = नीति + इक + ता
२. भारतीयता = भारत + ईय + ता
३. मानवीयता = मानव + ईय + ता (या भौतिकता = भूत + इक + ता)
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २७ पर विशेष सारणी।
आदर्श उत्तर: १. बद (बुरा): बदनाम, बदमाश
२. बे (बिना): बेईमान, बेकसूर
३. गैर (भिन्न/बिना): गैरहाज़िर, गैरसरकारी
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २४ पर विदेशी उपसर्गों की सूची।
आदर्श उत्तर: १. उत्कर्षपरक प्रभाव: यह मूल शब्द के अर्थ में श्रेष्ठता, सकारात्मकता या तीव्रता लाता है; जैसे—बल से प्रबल, मान से सम्मान।
२. निषेधात्मक प्रभाव: यह मूल शब्द के अर्थ को विपरीतार्थक (विलोम) बना देता है या अभाव प्रकट करता है; जैसे—ज्ञान से अज्ञान, यश से अपयश।
स्रोत/व्याख्या: पाठ्यपुस्तक पृष्ठ २३ पर उपसर्गों के मुख्य प्रभाव।
