## 1. Chapter Overview & Core Theoretical Principles

> **Syllabus Scope**: Concepts of decimal places (tenths, hundredths, thousandths), expanded forms, comparing decimal numbers, converting fractions to decimals, metric unit conversions, and real-life additions and subtractions.

### Decimal Place Value Table
Each position to the right of the decimal point represents a fraction of 10:
- Tenths: $\frac{1}{10} = 0.1$
- Hundredths: $\frac{1}{100} = 0.01$
- Thousandths: $\frac{1}{1000} = 0.001$
Example: $32.475 = 30 + 2 + \frac{4}{10} + \frac{7}{100} + \frac{5}{1000}$.

### Comparing Decimals
To compare two decimals: Compare the whole number parts first; if equal, compare tenths, then hundredths, and so on.

### Metric Conversions using Decimals
- Length: $1\text{ mm} = 0.1\text{ cm}$; $1\text{ cm} = 0.01\text{ m}$; $1\text{ m} = 0.001\text{ km}$.
- Mass: $1\text{ g} = 0.001\text{ kg}$.
- Money: $1\text{ Paise} = ₹0.01$.

#### [MTG_MATH3_SA_001] Reema bought $3.5\text{ kg}$ of potatoes at ₹24.50 per kg and $2.25\text{ kg}$ of tomatoes at ₹40 per kg. How much change did she receive from a ₹200 note?

#### [MTG_MATH3_LA_001] Convert and evaluate the following in standard SI units:
(a) Express ₹8 and 75 paise in Rupees.
(b) Convert $7\text{ km } 45\text{ m}$ into kilometers.
(c) Convert $5\text{ kg } 8\text{ g}$ into kilograms.
- **Difficulty**: `hard_hots` | **Marks**: `5` | **Topic**: `Comprehensive Metric Conversions` | **Source**: `chapter_notes`
- **Step-by-Step Model Solution**:
  • **(a) Rupees**:
  $$1\text{ rupee} = 100\text{ paise} \implies 75\text{ paise} = ₹0.75$$
  $$₹8 + ₹0.75 = \mathbf{₹8.75}$$
• **(b) Kilometers**:
  $$1\text{ km} = 1000\text{ m} \implies 45\text{ m} = \frac{45}{1000}\text{ km} = 0.045\text{ km}$$
  $$7\text{ km} + 0.045\text{ km} = \mathbf{7.045\text{ km}}$$
• **(c) Kilograms**:
  $$1\text{ kg} = 1000\text{ g} \implies 8\text{ g} = \frac{8}{1000}\text{ kg} = 0.008\text{ kg}$$
  $$5\text{ kg} + 0.008\text{ kg} = \mathbf{5.008\text{ kg}}$$
- **Marking Rubric & Working Notes**: Decimal base-10 and base-1000 metric conversions.
