### Mathematical Reasoning

#### Q16. [Fractions of Money] (1 Mark)
- **Correct Option**: **(A)**
- **Comprehensive Solution**: Remaining fraction $= 1 - \left(\frac{1}{3} + \frac{1}{4}\right) = 1 - \frac{7}{12} = \frac{5}{12}$.

#### Q17. [Profit Algebraic Formulation] (1 Mark)
- **Correct Option**: **(B)**

#### Q18. [Linear Equations] (1 Mark)
- **Correct Option**: **(D)**
- **Comprehensive Solution**: $5(x - 8) - 14(x - 11) + 8\left(x - \frac{11}{4}\right) = 0 \implies 5x - 40 - 14x + 154 + 8x - 22 = 0 \implies -x + 92 = 0 \implies x = 92$.
