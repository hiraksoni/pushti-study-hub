वर्णमात्रा-परिचयः (Alphabets, Vowels, Matras)

In Sanskrit, the time taken to pronounce a vowel is measured in "Matras".

  • ह्रस्वः (Hrasva) - 1 Matra (e.g. अ, इ, उ, ऋ)
  • दीर्घः (Dirgha) - 2 Matras (e.g. आ, ई, ऊ, ए, ऐ, ओ, औ)
  • प्लुत ः (Pluta) - 3 Matras (e.g. अ३, ऊ३)

Consonants (व्यञ्जनम्) have only half a matra (अर्धमात्रा).

Practice Exercise: Matra Counting

Count the total matras for the following words:

1. रामः (र् + आ + म् + अ + ः) 4.5 Matras (0.5 + 2 + 0.5 + 1 + 0.5)
2. सीता (स् + ई + त् + आ) 5 Matras (0.5 + 2 + 0.5 + 2)

सन्धिः (स्वरसन्धिः - परिशिष्टम् २ / Ch 15)

उच्चारणसमये परस्परं वर्णानाम् अत्यन्तं सामीप्यं 'संहिता' भवति। यत्र संहिताद्वारा वर्णानां परिवर्तनं भवति तस्यैव 'सन्धिः' इति नाम।

१. सवर्णदीर्घ-सन्धिः

नियमः: अ/आ + अ/आ = आ | इ/ई + इ/ई = ई | उ/ऊ + उ/ऊ = ऊ | ऋ/ॠ + ऋ/ॠ = ॠ

सन्धिपदम्विच्छेदःनियमः
तत्रापितत्र + अपिअ + अ = आ
तथापितथा + अपिआ + अ = आ
रवीन्द्रःरवि + इन्द्रःइ + इ = ई
गौरीतिगौरी + इतिई + इ = ई
गुरूपदेशःगुरु + उपदेशःउ + उ = ऊ
मातृणम्मातृ + ऋणम्ऋ + ऋ = ॠ

२. गुण-सन्धिः

नियमः: अ/आ + इ/ई = ए | अ/आ + उ/ऊ = ओ | अ/आ + ऋ/ॠ = अर्

सन्धिपदम्विच्छेदःनियमः
सुरेन्द्रःसुर + इन्द्रःअ + इ = ए
कथेतिकथा + इतिआ + इ = ए
परोपकारःपर + उपकारःअ + उ = ओ
महोत्सवःमहा + उत्सवःआ + उ = ओ
सप्तर्षिःसप्त + ऋषिःअ + ऋ = अर्
महर्षिःमहा + ऋषिःआ + ऋ = अर्

३. वृद्धि-सन्धिः

नियमः: अ/आ + ए/ऐ = ऐ | अ/आ + ओ/औ = औ

सन्धिपदम्विच्छेदःनियमः
एकैकम्एक + एकम्अ + ए = ऐ
तथैवतथा + एवआ + ए = ऐ
परमौषधिःपरम + ओषधिःअ + ओ = औ
मधुरौदनम्मधुर + ओदनम्अ + ओ = औ

४. यण्-सन्धिः

नियमः: इ/ई + असवर्ण स्वर = य् | उ/ऊ + असवर्ण स्वर = व्

सन्धिपदम्विच्छेदःनियमः
इत्यपिइति + अपिइ + अ = य्
तान्येवतानि + एवइ + ए = ये
मध्वरिःमधु + अरिःउ + अ = व्
स्वागतम्सु + आगतम्उ + आ = वा

Practice Exercise: सन्धिं सन्धिविच्छेदं वा कुरुत (Exam Style)

1. सुर + ईशः = सुरेशः (गुणसन्धिः)
2. महा + उत्सवः = महोत्सवः (गुणसन्धिः)
3. तथा + एव = तथैव (वृद्धिसन्धिः)
4. सु + आगतम् = स्वागतम् (यण्सन्धिः)
5. विद्या + आलयः = विद्यालयः (दीर्घसन्धिः)
6. परोपकारः (विच्छेदः कुरुत) = पर + उपकारः (गुणसन्धिः)

अव्ययानि (Indeclinables - School Notebook Practice)

सदृशं त्रिषु लिङ्गेषु सर्वासु च विभक्तिषु। वचनेषु च सर्वेषु यन्न व्येति तदव्ययम्॥
(Words whose forms never change according to gender, case, or number are called अव्यय).

मञ्जूषातः समुचितम् अव्ययपदं चित्वा रिक्तस्थानानि पूरयन्तु

मञ्जूषा: (अधः, उपरि, उच्चैः, मा, तीव्रम्, विना, कदा, च, सर्वत्र, प्रातः)
1. वृक्षस्य उपरि खगाः सन्ति। (ऊपर)
2. धनेन विना सुखं नास्ति। (बिना)
3. मेघाः उच्चैः गर्जन्ति। (जोर से)
4. छात्राः प्रातः विद्यालयं गच्छन्ति। (सुबह)
5. रामः श्यामः च पठतः। (और)
6. ईश्वरः सर्वत्र अस्ति। (सब जगह)
7. त्वं कदा दिल्लीनगरं गमिष्यसि? (कब)
8. अश्वः तीव्रम् धावति। (तेज़)
9. असत्यं मा वद। (मत)
10. वृक्षस्य अधः बालकाः क्रीडन्ति। (नीचे)
