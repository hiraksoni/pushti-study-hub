उच्चारणसमये परस्परं वर्णानाम् अत्यन्तं सामीप्यं 'संहिता' भवति। यत्र संहिताद्वारा वर्णानां परिवर्तनं भवति तस्यैव 'सन्धिः' इति नाम।

व्याकरण-परिचयः

संस्कृतभाषायां वर्णानां मेलनेन जायमानः विकारः सन्धिः उच्यते। अस्य त्रयः भेदाः सन्ति:

१. स्वरसन्धिः (अच्-सन्धिः)
स्वरवर्णस्य स्वरेण सह मेलने यत् परिवर्तनं जायते, सा स्वरसन्धिः। यथा: विद्या + आलयः = विद्यालयः।
२. व्यञ्जनसन्धिः (हल्-सन्धिः)
व्यञ्जनवर्णस्य व्यञ्जनेन स्वरेण वा सह मेलने यत् परिवर्तनं भवति। यथा: सत् + जनः = सज्जनः, तत् + एव = तदेव।
३. विसर्गसन्धिः
विसर्गस्य (: ) स्वरेण व्यञ्जनेन वा सह मेलने सति विसर्गे यत् रूपान्तरं भवति। यथा: रामः + गच्छति = रामो गच्छति, इतः + अपि = इतोऽपि।

१. सवर्णदीर्घ-सन्धिः (अकः सवर्णे दीर्घः)

यदा ह्रस्वः दीर्घः वा अ, इ, उ, ऋ वर्णः स्वसमानवर्णेन सह मिलति, तदा तयोः स्थाने सवर्णदीर्घः एकादेशः भवति।

सन्धिपदम्विच्छेदःनियमःआङ्ग्ल-विवरणम्
तत्रापितत्र + अपिअ + अ = आThere also
तथापितथा + अपिआ + अ = आEven then
रवीन्द्रःरवि + इन्द्रःइ + इ = ईLord of the Sun
मुनीशःमुनि + ईशःइ + ई = ईLord of Sages
नदीश्वरःनदी + ईश्वरःई + ई = ईLord of Rivers (Ocean)
भानूदयःभानु + उदयःउ + उ = ऊSunrise
पितॄणम्पितृ + ऋणम्ऋ + ऋ = ॠAncestral debt

२. गुण-सन्धिः (आद्गुणः)

अ/आ वर्णात् परे इ/ई वर्णे सति 'ए', उ/ऊ वर्णे सति 'ओ', ऋ वर्णे सति 'अर्' भवति।

सन्धिपदम्विच्छेदःनियमःआङ्ग्ल-विवरणम्
सुरेशःसुर + ईशःअ + ई = एKing of Gods (Indra)
महेशःमहा + ईशःआ + ई = एGreat Lord (Shiva)
सूर्योदयःसूर्य + उदयःअ + उ = ओSunrise
महोत्सवःमहा + उत्सवःआ + उ = ओGreat Festival
परोपकारःपर + उपकारःअ + उ = ओBenevolence / helping others
महर्षिःमहा + ऋषिःआ + ऋ = अर्Great Sage
देवर्षिःदेव + ऋषिःअ + ऋ = अर्Divine Sage (Narada)

३. वृद्धि-सन्धिः (वृद्धिरेचि)

अ/आ वर्णात् परे ए/ऐ वर्णे सति 'ऐ', ओ/औ वर्णे सति 'औ' भवति।

सन्धिपदम्विच्छेदःनियमःआङ्ग्ल-विवरणम्
तथैवतथा + एवआ + ए = ऐIn the same manner
अद्यैवअद्य + एवअ + ए = ऐToday itself
एकैकम्एक + एकम्अ + ए = ऐOne by one
सदैवसदा + एवआ + ए = ऐAlways
महौषधिःमहा + औषधिःआ + औ = औGreat medicine

४. यण्-सन्धिः (इको यणचि)

इ/ई, उ/ऊ, ऋ वर्णेभ्यः परे असमानस्वरः आगच्छति चेत् क्रमात् 'य्', 'व्', 'र्' भवन्ति।

सन्धिपदम्विच्छेदःनियमःआङ्ग्ल-विवरणम्
यद्यपियदि + अपिइ + अ = य् + अ = यEven if / although
इत्यादयःइति + आदयःइ + आ = याEtc. / and so on
अत्युत्तमम्अति + उत्तमम्इ + उ = युSuperb / Excellent
स्वागतम्सु + आगतम्उ + आ = वाWelcome
मध्वरिःमधु + अरिःउ + अ = वEnemy of Madhu (Vishnu)

५. अयादि-सन्धिः (एचोऽयवायावः)

यदा ए, ऐ, ओ, औ एतेभ्यः परे कोऽपि स्वरः आगच्छति, तदा क्रमात् 'अय्', 'आय्', 'अव्', 'आव्' भवन्ति।

नयनम्ने + अनम्ए + अ = अय् + अ = अयEye
चयनम्चे + अनम्ए + अ = अय् + अ = अयSelection / Gathering
गायकःगै + अकःऐ + अ = आय् + अ = आयSinger

६. पूर्वरूप-सन्धिः (एङ्ः पदान्तादति) • अवग्रह-नियमः (ऽ)

⭐ NCERT Deepakam Ch. 15 Page 7

पदान्ते स्थितात् 'ए' अथवा 'ओ' वर्णात् परे यदि ह्रस्वः 'अ' आगच्छति, तर्हि अ-कारः पूर्वरूपं भजते (लुप्तः भवति), तस्य स्थाने च अवग्रह-चिह्नं 'ऽ' (एस-सदृशं चिह्नम्) स्थाप्यते।

नियम-सूत्रम्: पदान्त 'ए' / 'ओ' + 'अ' → 'एऽ' / 'ओऽ'
सन्धिपदम्विच्छेदःघटक-वर्णौआङ्ग्ल-विवरणम्
तेऽपिते + अपिते (ए) + अपि (अ) → तेऽपिThey also
वनेऽत्रवने + अत्रवने (ए) + अत्र (अ) → वनेऽत्रIn this forest
छात्रोऽयम्छात्रो + अयम्छात्रो (ओ) + अयम् (अ) → छात्रोऽयम्This student
कोऽपिको + अपिको (ओ) + अपि (अ) → कोऽपिAnyone / Someone
सोऽवदत्सो + अवदत्सो (ओ) + अवदत् (अ) → सोऽवदत्He said
नृपोऽवदत्नृपो + अवदत्नृपो (ओ) + अवदत् (अ) → नृपोऽवदत्The king said
प्रभोऽत्रप्रभो + अत्रप्रभो (ओ) + अत्र (अ) → प्रभोऽत्रO Lord, here
💡 अवग्रहस्य उच्चारणम्: 'ऽ' चिह्नस्य पृथक् उच्चारणं न भवति, इदं केवलं पूर्वस्वरस्य किञ्चित् दीर्घीकरणं तथा लुप्त-अकारस्य सूचकम् अस्ति।

७. प्रकृतिभाव-सन्धिः (ईदूदेद् द्विवचनं प्रगृह्यम्) • सन्धेः अभावः

⭐ NCERT Deepakam Ch. 15 Page 7

यत्र सन्धेः प्राप्तेः सत्याम् अपि नियमानुसारेण सन्धिकार्यं न भवति, वर्णाः च स्वप्रकृतौ (मूलस्वरूपे) एव तिष्ठन्ति, सः 'प्रकृतिभावः' कथ्यते। ईकारान्त, ऊकारान्त तथा एकारान्त द्विवचन-पदानां (प्रगृह्य-संज्ञक-पदानां) परे स्वरः आगच्छति चेत् सन्धिः न भवति।

नियम-सूत्रम्: द्विवचनस्य ई / ऊ / ए + कोऽपि स्वरः → प्रकृतिभावः (विकार-रहितं मूलरूपम्)
प्रकृतिभाव-पदम्विच्छेदःप्रगृह्य-द्विवचन पदम्विवरणम्
हरी एतौहरी + एतौहरी (इकारान्त द्विवचनम्)सन्धिः न भवति (No change, remains separated)
गङ्गे अमूगङ्गे + अमूगङ्गे (आकारान्त-स्त्रीलिङ्ग द्विवचनम्)सन्धिः न भवति (गङ्गे अमू)
लते एतेलते + एतेलते (लता शब्दस्य द्विवचनम्)सन्धिः न भवति (लते एते)
कवी इमौकवी + इमौकवी (कवि शब्दस्य द्विवचनम्)सन्धिः न भवति (कवी इमौ)
साधू इमौसाधू + इमौसाधू (साधु शब्दस्य द्विवचनम्)सन्धिः न भवति (साधू इमौ)
बालिके आगच्छतःबालिके + आगच्छतःबालिके (बालिका शब्दस्य द्विवचनम्)सन्धिः न भवति (Two girls come)
💡 परीक्षा-दृष्ट्या: यदा परीक्षायां 'हरी + एतौ' इत्यस्य सन्धिपदं पृच्छ्यते, तदा उत्तरम् 'हरी एतौ' (प्रकृतिभावः) इति एव लेखनीयम्, यण्-सन्धिः न भवति।
