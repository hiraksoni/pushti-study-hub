🔢 Introduction to Number Systems

🌍 What is a Number System?

A Number System is a mathematical notation used to represent numbers that in turn represent a quantity.

Computers only understand machine language, which is made up of numbers. That's why we need number systems to convert instructions into something a computer can process.

💡 Remember: There are 4 main number systems: Decimal, Binary, Octal, and Hexadecimal.
🔟 Decimal Number System

Base 10

The decimal system uses 10 digits (0 to 9).

It is a positional number system. The value of each digit depends on its position. Each position represents a specific power of 10.

Example: 1234
= (1 × 10³) + (2 × 10²) + (3 × 10¹) + (4 × 10⁰)
= 1000 + 200 + 30 + 4

The leftmost digit is the Most Significant Digit (MSD) and the rightmost is the Least Significant Digit (LSD).

⚙️ Binary Number System

Base 2

The binary system uses only 2 digits: 0 and 1.

Its base is 2, meaning positional values are based on powers of 2 (2⁰, 2¹, 2², etc.).

Conversion to Decimal: 11000
= (1 × 2⁴) + (1 × 2³) + (0 × 2²) + (0 × 2¹) + (0 × 2⁰)
= 16 + 8 + 0 + 0 + 0 = 24

⚙️ Why Binary?

Bonus
On and Off! Computers are built using millions of tiny electronic switches called transistors. A transistor can only be in one of two states: ON (1) or OFF (0). That's why the binary system is perfectly suited for machines!

🔠 Why Hexadecimal uses Letters

Bonus
Running out of numbers! In base 16, we need single digits to represent values from 10 to 15. If we just wrote "10", a computer wouldn't know if we meant the number 10, or a "1" followed by a "0". So, scientists decided to borrow letters A through F!
