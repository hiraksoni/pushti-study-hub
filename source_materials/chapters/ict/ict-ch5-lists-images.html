📋 Introduction to HTML Lists

Significance of Lists in a Web Page

Lists are used to group and associate together related content so that it is easy to read. They arrange relevant content in an easy-to-read and easy-to-maintain format. Lists provide a well-structured and semantic way to display information.

The <li> Tag

  • The individual items of a list are marked with the <li> (List Item) tag.
  • This tag allows you to provide List Items in both ordered and unordered lists.

Nested Lists

When you create a list inside another list, it is called a Nested List.

🔢 Types of HTML Lists

1. Unordered List

  • An unordered list is a set of related information that does not have any special order or sequence.
  • It looks like a bullet list.
  • Represented by the <UL> tag.
  • It allows symbols like bullets to mark items.
  • TYPE Attribute: Used to define the symbol for the bullets. The default bullet style is a Disc. Other values include Circle and Square. (Note: Rectangle cannot be a value).

2. Ordered List

  • An ordered list has items assigned a number from first to last in an increasing order (or decreasing).
  • It looks like a numbered list.
  • Represented by the <OL> tag.
  • Also known as a numbered list.

Attributes of <OL> tag

  • TYPE: Defines the numbering style. The default type is Arabic numbers (1, 2, 3...). Other types can be Alphabet letters (A, B, a, b) or Roman numbers (I, II, i, ii).
  • START: Specifies the starting number of the list.
  • REVERSED: The reversed attribute is used to reverse the counter in a list, making it order backwards. (So, an ordered list CAN be in reverse order).

3. Definition List

  • A definition list is a list of terms, with a description of each term.
  • Two situations to use it: Glossaries or displaying a list of terms and their definitions.
  • There are 3 tags used to create a definition list:
    1. <DL>: Used for creating definition lists.
    2. <DT>: Used to define the definition term.
    3. <DD>: Used to define the data description.

🎨 CSS List Properties

Styling Lists

CSS offers several properties to style the markers (bullets or numbers) of HTML lists.

Various CSS List Properties

  • list-style-type: Specifies the type of list-item marker (e.g., square, circle, lower-alpha).
  • list-style-image: Replaces the list-item marker with a custom image.
  • list-style-position: Specifies whether the marker should appear inside or outside the content flow.

🖼️ Images in HTML

Why Insert Images?

We insert images in a web page because the use of images makes it visually appealing. Images grab attention, illustrate concepts, and improve the overall design.

The <img> Tag and its Attributes

Images are inserted using the <IMG> tag.

  • SRC (Source): Specifies the URL or address of the image file. It tells the browser where to find the image.
  • ALT (Alternate Text): An attribute used to display some text if the image cannot be displayed for some reason (e.g. slow connection or broken link). It also helps visually impaired users who use screen readers.
  • HEIGHT & WIDTH: Used to specify the dimensions of the image.

Common Image Formats

  • .jpg: Joint Photographic Experts Group. Used commonly for photos.
  • GIF: Graphics Interchange Format. Often used for simple graphics or animations.

✨ The Marquee Tag

Scrolling Text

The <marquee> tag is used to add a marquee (a moving text) to a web page. It creates a scrolling text or image effect.

Marquee Attributes

  • direction: Sets the direction of the scroll (left, right, up, down).
  • behavior: Defines how it moves (scroll, slide, alternate).
  • scrollamount: Sets the speed of the scrolling text.
  • bgcolor: Sets a background color for the marquee area.

Example:

<marquee direction="right" bgcolor="yellow">Welcome to my website!</marquee>

🧐 Semantic HTML with Lists

Lists aren't just for bullets! Modern web developers use <ul> and <li> tags to build navigation bars, drop-down menus, and grid layouts. CSS is used to remove the bullets and style them horizontally.

Even the navigation menu on websites like YouTube and Google use unordered lists under the hood — styled entirely with CSS!

🧠 The Fall of Marquee

Did you know the <marquee> tag is obsolete in HTML5? It was heavily used in the early days of the web, but today, scrolling and animation effects are done strictly using CSS Animations or JavaScript, as they are smoother and more accessible.

However, your textbook still includes it, so make sure to know its attributes (direction, behavior, scrollamount, bgcolor) for your exams!
