Chapter 04 Computer (ICT)

Working with HTML Tags and CSS

Exploring basic HTML elements and styling them using Cascading Style Sheets

📖 Chapter at a Glance

This chapter introduces you to the essential elements of web page design using HTML tags and CSS. You will learn about structural tags, how to format text, adding comments, and styling your page with Cascading Style Sheets (CSS) to make it visually appealing.

🎯 Learning Outcomes

  • Understand HTML structural elements and body attributes like BGCOLOR and BACKGROUND
  • Learn text formatting tags such as paragraph alignment, fonts, subscript, and superscript
  • Implement HTML comments using the <!-- --> and older <COMMENT> tags
  • Understand Cascading Style Sheets (CSS) and its syntax
  • Explore Inline, Internal, and External CSS
  • Apply CSS properties for background, text, and fonts

📘 Key Terms Glossary

Tags
The fundamental elements of an HTML document used to instruct the browser how to display content.
Attributes
Additional properties inside tags that provide more styling or functionality options.
CSS
Cascading Style Sheets. It is used to format the layout of a webpage and make it more attractive.
Selector
The part of a CSS rule that indicates which HTML element is to be styled.
Declaration Block
The part of a CSS rule containing formatting properties and their values, enclosed in curly brackets {}.
Comments
Hidden notes in an HTML document that the browser does not display. They help explain the code.

🌐 Body Tag Attributes

The <body> Tag

The <body> tag contains the actual content of the web page that is visible to users. We can add attributes to this tag to customize the page's appearance.

Common Body Attributes

  • BGCOLOR: Used to set the background color of the webpage. (e.g. <body bgcolor="yellow">)
  • TEXT: Sets the color of the text for the entire webpage.
  • BACKGROUND: Used to insert an image in the background of a web page.

Link Attributes in Body

  • LINK: Sets the color of unvisited links. Default is blue.
  • ALINK: Sets the color of an active link (when you click on it). Default color is red.
  • VLINK: Sets the color of visited links. Default is purple.

✍️ Formatting Tags

What are Formatting Tags?

These tags are used to format the text and paragraphs in your webpage to make them look better and more structured.

Paragraph and Break Tags

  • <P> tag: Used to display text in a paragraph format. It can take the ALIGN attribute (e.g. align="center", "left", "right").
  • <BR> tag: Used to insert a new line. It does not have an end tag.

Font Tag

  • The <FONT> tag changes the appearance of text.
  • FACE: Changes the font type or style (e.g. Arial).
  • COLOR: Changes the color of the text.
  • SIZE: Changes the size of the font.

Subscript and Superscript

  • <SUB>: Displays text slightly below the normal line (Subscript, e.g. H2O).
  • <SUP>: Displays text slightly above the normal line (Superscript, e.g. X2).

📝 HTML Comments

What are Comments?

Comments can be added in a web page to explain the code. They are completely ignored by the web browser and are only visible when looking at the source code.

Ways to Add Comments

  • Using `<!-- -->`: The standard way to add comments. (e.g. <!-- This is a comment -->)
  • Using `<COMMENT>`: An older, obsolete tag used to add comments in a web page.

🎨 Introduction to CSS

What is CSS?

CSS stands for Cascading Style Sheets. They are used to format the layout of a webpage. CSS allows you to apply consistent styles across multiple HTML elements.

CSS Syntax

A CSS rule contains two parts:

  • Selector: The HTML tag you want to style.
  • Declaration Block: Enclosed in `{ }`, it contains one or more declarations separated by a semicolon. Each declaration has a property and a value, separated by a colon.
h1 { color: blue; font-size: 12px; }

📋 Types of CSS

Linking CSS to HTML

HTML documents can be linked to inline, internal, and external style sheets.

1. Inline Style Sheet

  • Applies a unique style to a single HTML element.
  • Uses the style attribute inside the HTML tag.
  • Disadvantage: It is not an efficient use of a style sheet as the declaration must be repeated with every element.

2. Internal Style Sheet

  • Used for a single webpage.
  • Defined inside the <style> tag within the <head> section.
  • Advantage over inline: The effect gets applied to all the elements of the type with which the style declaration has been specified.
  • Disadvantage: Not an efficient use of a style sheet if you have multiple pages.

3. External Style Sheet

  • The CSS is written in a separate file (with a .css extension).
  • External style sheets are useful because you can link them to more than one HTML document, ensuring a consistent look across a whole website.

✨ CSS Properties

Styling Backgrounds and Fonts

CSS provides various properties to format backgrounds and typography.

Background Properties

  • background-color: Specifies the background color.
  • background-image: To add a background image to the webpage.
  • background-position: Specifies where the background image should be placed.
  • background-repeat: Sets how background images are repeated (e.g. along horizontal/vertical axes).

Font Properties

  • font-size: Used to define the size of the font.
  • font-family: Used to change the face of a font (e.g., Arial, Courier). (Generic families include Serif, Sans-serif; Constantia is a family name, not generic).
  • font-style: Make a font italic or oblique.
  • font-weight: Increases or decreases the boldness.
  • font-variant: Creates a small-caps effect.
  • font: Shorthand to specify all font properties in one line.

🧐 Evolution of HTML Elements

Tags like <FONT> and <COMMENT> are actually deprecated in HTML5! Today, developers strictly use CSS for styling instead of <font>, and <!-- --> is the only accepted way to write comments.

However, your textbook teaches both the old and new approaches, so it's important to know them for your exams. In the real world, always prefer CSS over inline HTML formatting tags.

🧠 The Cascade in CSS

Why is it called "Cascading"? It refers to the hierarchy of styles that determines which style "wins" when multiple rules apply:

  • Inline CSS (highest priority) → overrides everything
  • Internal CSS (medium priority) → overrides external
  • External CSS (lowest priority) → base styles

This priority order is why it's called a "cascade" — styles flow down from highest to lowest priority, like a waterfall!
